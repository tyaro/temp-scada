# I7：共有Symbol内の静止画像

2026-10-21（日本時間）。状態: **I7aの資産参照基盤を実装・ローカル検証済み。Symbol内画像の機能は未提供**。[単体開発計画](upstream-independent-plan.md)で、既存Imageの共有Symbolへの再利用を段階化する。Astraの読取レビューを反映した。統合設計・現在の[画像配置仕様](image-placement-design.md)を置き換えず、公開する範囲ごとに保存・描画・コピーを揃える。

## 初回の対象と除外

目標はPNG／JPEGの静止画像をSymbol定義に持ち、原本を共有しながら配置・回転・opacity・fit・cropを既存Imageと同じ規則で扱うこと。未配置定義・非表示配置の原本も保存する。外部URL・SVG取込・動画・Symbol入れ子・任意拡縮・新しいAssetStoreは含めない。

現行Project0.33.0はSymbol内Imageを拒否する。**I7aでこの拒否は外さない**。低層の参照集計が対応することと、公開validator／command／UIで利用できることを区別する。リリース前の旧形式互換は必須にしないが、保存属性を拡張するときはTS／Rust／schema／サンプルを同時に更新する。

## 資産の保持とコピーの範囲

| 用途                              | 必要な資産                                                                                                                                    |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Project保存・検証・現在状態の剪定 | 全画面の背景／Image、全Symbol定義内のImage。未配置・非表示・ロックを理由に除外しない                                                          |
| 選択配置のclipboard               | 選択配置から到達する埋込画面・Symbolと画像だけ。到達した画面の背景も含む。無関係な定義・資産は混ぜない                                        |
| 貼り付け                          | 先に実際に取り込む画面／定義を決め、内部画像だけ資産登録・ID再配線。同一workspaceの現行定義を再利用するときは古いsnapshotの資産を復活させない |
| Undo／Redo・書出し中              | 現在Projectだけの参照と区別し、既存の履歴保持・原本pin／leaseの寿命を維持する                                                                 |

参照索引はasset IDと所有者種別・所有者ID・配置IDを返す。重複する原本の集合化は利用側で行い、索引から使用先を消さない。資産宣言の欠落を索引で補修・黙って除外しない。公開validatorが欠落・孤立宣言・不正crop等を拒否する。

閉包収集は重複訪問を止めるが、深さ・循環・Symbol入れ子の許可を判断しない。既存Project検証が構造の正となる。参照収集の対応を理由に、貼付時の現行定義再利用・asset ID付替えを省略しない。

## 描画・色とαの後続契約

Astraの推奨を後続実装の基準案とする。画像のRGBと原本αは両colorModeで保持し、単色RGBの置換は既存の図形・文字・線に限定する。子Imageのopacityはその画像へ、Symbol配置opacityは合成後の全体へ一回適用する。

単色SymbolのcolorAlphaは現行の[合成後の契約](color-alpha-design.md)を維持し、**画像を含む全体**に作用することをUI・仕様に明記する。定義色では従来どおり非適用。colorAlphaを子ベクタに個別乗算すると重なりの濃さが変わり、全ベクタをまとめると「ベクタ→画像→ベクタ」の順序が変わるため、その代替実装は行わない。I7aでは描画・opacity・colorAlphaを変更しない。
