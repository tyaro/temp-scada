# 配置の回転（次の実装工程）

文書の位置付け: **採用済み設計・導入時の実装記録。文中の旧版・件数・当時の未実装表記は記録時点のもの。** 現在の対応範囲と保存契約は[実装状況](implementation-status.md)を正とする。

状態: **0.11.0で実装済み**。[統合設計](scada-integrated-design.md)の図形編集を拡張する。Astraは機器の向き違いを共有定義の複製で作る負担を減らす工程として推奨した。上流の[座標とpivotの契約](upstream/industrial/scada-design.md)を参照し、原本は変更しない。

## 保存と対象

矩形・楕円・Text・Polyline・Symbolの共通配置属性に角度rotationを保存する。時計回りのdegree、有限値、0以上360未満に正規化する。新規配置は0。同値・360の整数倍だけの差では履歴を作らない。Project 0.11.0でRust／TypeScript／schema／現在のサンプル／生成経路を揃える。リリース前の旧中間形式は移行しない。

pivotはモデル上の未変換local layout boundsの中心。矩形・楕円・Textは本体寸法、Polylineは頂点の幾何bounds（線幅・矢印の余白を除く）を使う。Symbolは宣言viewportの中心を、配置のwidth／heightとxMidYMid meetを通じて使う。内部図形のunionやSVG DOMのgetBBoxを使わず、内部編集で既存配置の中心を動かさない。explicit pivotは後続。回転は配置だけを変更し、別配置の配管やラベルの接続・自動引き回しは行わない。

UI／コマンドは負角・360°以上を正規化するが、保存JSONは正規形だけを受理する。直角のsin／cosには正確な0／±1を使い、不要な微小誤差を避ける。

配置のx／yとwidth／height、頂点は回転前の座標のまま。描画はtranslate(x,y)の内側にpivotを中心とするrotateを合成する。共有定義の内部図形も個別に回転でき、Symbol配置の回転と合成する。Symbol配置の回転では共有定義と他の配置を変更しない。Editor・表示プレビュー・ミニマップ・部品の定義プレビューで同じ描画規則を使う。レイヤー／部品の種類アイコンに配置ごとの角度は反映しない。共有定義のサムネイルは内部図形の角度を反映する。

## 外形と操作

未変換の本体／描画外形と、回転後の所有先座標の描画外接範囲を区別する。枠線・線幅・矢印を含む外形の四隅を変換して保守的な外接範囲を求め、選択・整列・範囲選択・貼付・選択範囲の表示に使う。精密な曲線の最小boundsまでは保証しない。回転0の既存表示と操作は維持する。

移動は所有先座標のdeltaをそのままx／yへ加える。移動ドラッグは既存の掴んだ配置の原点基準スナップを維持する。配置の方向キー移動は既存の描画外形基準を維持する。リサイズハンドルは回転後の本体辺・頂点に置き、ポインタdeltaを逆回転して本体寸法を変更する。反対側の辺／頂点を所有先上で固定するため、サイズ変更によるpivotの変化に合わせx／yも補正する。反転はせず最小1 unitとする。

角ハンドルは画面上のハンドル位置をスナップしてから逆変換する。辺ハンドルはポインタのdeltaを回転した辺の法線へ射影する。スナップONでは法線の主成分軸（同値ならX）の画面グリッドへ合わせ、残る軸を法線の拘束から求める。回転0では従来の辺スナップ規則を維持する。方向キーも同じ射影とスナップを使い、法線と直交するキーはno-opとする。ポインタではAltでスナップを一時解除する。origin補正の後に再度座標を丸めず、反対辺の固定を維持する。

Polylineの頂点は所有先上のポインタ位置から逆変換する。頂点編集による暗黙pivotの変化で、触れていない頂点が移動しないようx／yを同時補正する。ドラッグ中のプレビューとコマンド確定で同じ計算を共用する。方向キーの意味も画面座標に合わせる。pointerドラッグは既存の0.5 unit以下の不動域・スナップOFF時のdeltaだけの0.01丸め・スナップON時の両軸吸着を維持する。keyboardは不動域とpointer丸めを通さず、操作する軸だけ次のグリッドへ進める。操作開始時の変換・頂点を基準とし、毎frameの補正済み値を基準にして誤差を蓄積しない。数値プロパティによる寸法／頂点変更は保存属性を直接編集する既存の意味を維持し、ドラッグと区別して説明する。

## UI・入力保護

単一選択の配置プロパティに角度を追加し、既存の数値Enter／フォーカス移動による確定、Esc取消、IME、十進数検証を共用する。共通操作の左／右90°はツールバーと既存編集メニューへ置く。角度のdraftと他の未適用入力は既存guardで保護し、ドラッグ・対象変更・Undoで迂回しない。lockedは変更不可、hiddenは既存の明示編集を維持する。

回転ハンドル・任意pivot・複数配置の共通中心による回転・幾何グループは含めない。

## 受入

0／90／180／270°と任意角、正負・360°以上の入力、NaN／Infinity／不正文字、同値、90°を4回、Undo／Redo、JSON往復を確認する。負座標・太い枠線・矢印・非正方形Symbol・内部回転と親回転の合成、各表示経路を含める。

回転後の移動／整列／範囲選択／選択fit／貼付、反対辺を固定するリサイズ、未操作頂点を固定する頂点移動を検証する。両テーマ・狭幅・倍率・スナップ・Alt解除・キー操作・draft取消／不正入力・lock／hidden・読込世代の境界も確認する。実装完了時に実画面と実施済み件数を開発計画へ記録する。

## レビューでの調整

選択枠・範囲判定・整列は回転後の外接範囲を使う。ポインタの透明クリック領域は未回転の描画外形へ回転を適用し、外接枠の空白角で背後の配置を遮らない。Polylineのクリック領域にも同じ回転を使う。リサイズカーソルはハンドルの実際の向きに近い標準カーソルへ切り替える。

Astraが保存契約・生成経路・描画合成・頂点補正・0°互換を読み取りレビューした。クリック領域を上記の規則へ修正し、斜めの細長い配置の空白角から背後の配置を選べるブラウザ検証を追加した。

左右90°を追加した際に、右クリックがツールバーグループの配列番号を参照していた問題を修正した。グループを安定した内部IDで参照し、単一選択では回転と重なり順、複数選択では整列・等間隔配置を提示する。並び順の追加で既存メニューの内容を取り違えない。

実施済みの検証と両テーマの実画面は[開発計画](implementation-history.md#object-rotation-progress)を参照する。
