# 機器登録・画面再利用の操作試作

2026-10-20（日本時間）。[詳細検討書](../../design/proposals/equipment-authoring-detail-proposal.md)の段階Aを確認する独立試作。本体アプリとは接続しない。

## 開き方

`standalone.html`を手元のPCへ保存し、Chrome／Edgeで開く。HTML・CSS・JavaScriptを1ファイルに収めており、ネットワークや追加インストールを必要としない。ブラウザ側の管理ポリシーでローカルHTMLが禁止されている場合は、許可されたHTTPサーバー経由で開く必要がある。

## 試す順序

1. 初期のFAN-101は運転表示だけ採用し、タグは未割付。「この画面に表示を追加」で未割付時の表示を確認する。
2. 右の運転表示の「タグを選択」から`PLC01.FAN101.Run`を選び、「適用」。模擬の運転表示へ変わる。
3. 「送風系詳細」へ切り替えて同じ機器の表示を追加する。機器名の変更は両画面へ反映し、ドラッグや矢印キーによる配置移動は片方だけに反映する。
4. 電流表示を採用し、`PLC01.FAN101.Current`を割り付ける。既存の配置は変わらない。選択配置の表示形式を「記号と電流」へ切り替えると電流を表示する。
5. 「同じ機器の表示を複製」は機器IDと信号を共有する。「別機器として複製」は新番号・別IDの下書きを作り、すべての信号を未割付にする。「登録」まで台帳へ追加しない。
6. 左の模擬データで運転・停止・Stale・catalog未確認を切り替える。未採用・未割付・未確認・通信不明の違いを確認する。
7. 名称を入力途中で画面や機器を切り替える。「編集を続ける」で入力を保持し、「破棄して移動」で保存済みの設定へ戻る。

「＋登録」から信号なしの機器も作れる。機器番号は大文字小文字を区別せずProject内の重複を拒否する。機能解除は影響欄に案内し、「適用」で割付も解除、「入力を戻す」で保持する。

配置のドラッグはEscで取消。Tabで配置へフォーカスし、Enter／Spaceで選択、矢印キーで1px、Shift＋矢印で10px移動する。「元に戻す」は登録・設定・配置の変更を1件戻し、模擬の現在状態は戻さない。

## 保存と対象範囲

- 「試作データを書き出す」は適用済みの機器台帳と配置だけを、`equipment-authoring-study-v1`形式のJSONにする。実タグ参照は台帳に一度だけ持つ。
- ブラウザ内の自動保存・読込はない。再読込すると初期状態へ戻る。必要なデータは再読込前に書き出す。
- 本体Project形式への変換、実Hub接続、書込み、Faceplate、図面からの機器化、トレンドは含まない。
- catalog選択は同期の模擬処理。非同期の遅延応答・Project切替に対する世代管理は実装・検証していない。
- 型・既知の単位不一致を選択時に拒否する。単位metadataのない数値は選択可能で、表示に「単位未確認」と示す。
- 初期は送風機1種と運転・電流の2機能。停止・運転・電流の値は共通の模擬状態で、機器ごとにPLC値を再現するものではない。

## ブラウザ検証

```bash
source scripts/cloud-env.sh
node docs/prototypes/equipment-authoring/verify.cjs
```

リポジトリルートで依存をインストールしたうえで実行する。workspaceのPlaywrightと、`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`（未指定ならPlaywright管理のChromium）を利用。スクリプト内で一時HTTPサーバーを起動し、終了時に閉じる。`verification.json`に結果、`preview-1920x1080.png`と`preview-125-percent-equivalent.png`に画面を保存する。後者は1536×864 CSS pxで、1920×1080の125%表示に相当する領域の確認。OSの実際の表示倍率を変更した試験ではない。

39項目が成功。共有参照・表示形式の独立・別機器複製・未割付・入力保護・番号重複・型／単位拒否・マウス移動とEsc・キーボード・Undo・書出しを確認。1536×864と760×900で横はみ出しがないこと、固定ペインがキャンバスを覆わないことも確認した。利用者による所要時間・誤操作率の測定は未実施。
