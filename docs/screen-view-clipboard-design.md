# 埋込画面のコピーと貼り付け

2026-10-20。採用設計と実装範囲。[埋込View](embedded-screen-design.md)の後続工程。Projectは0.29.0のまま、図形clipboardのenvelopeにv4を追加する。埋込は引き続き1段であり、入れ子や自己参照の許可ではない。

## コピーする範囲

先頭画面は選択した配置だけの断片で、背景画像やフォルダーを含めず、配置をルートへ置く。選択に含む埋込Viewの参照画面を後続へ同梱する。同じ画面を複数のViewが参照していても1回だけ含める。参照画面は空でも有効で、隠れた配置・フォルダー・幾何グループ・背景画像のfit／crop／opacityを保持する。

選択配置と参照画面が使うSymbolと画像資産だけを含める。背景だけに使う原本も対象で、同じhashは一つに集約する。機器の関連付けを含む選択・参照画面は従来どおり拒否し、Project全体の保存を案内する。単体slot Textや状態色追従図形の既存制限も維持する。

v4には`images`を必ず置く。画像がなければ空配列、画像があれば原本のbase64を含める。宣言は4MiB、原本合計は16MiB、全体は32MiB以下。余分な画面・Symbol・資産、壊れた参照・原本hash・寸法・形式、余分なenvelope属性を拒否する。現行Projectの意味検証と埋込後の展開配置予算も適用する。

## 貼り付け

同じ編集セッション・Project世代・Project IDでは、存在する参照画面とSymbolを現行の定義として再利用する。コピー後の変更も反映する。現行画面を再利用した場合は、snapshotの古いSymbolや背景資産を追加しない。削除済みの参照画面はsnapshotから新しいIDで復元する。

別Project・再読込後は、参照画面とSymbolを新しいIDで取り込む。内部配置・フォルダー・グループ・状態色の参照も再発行し、画面／Symbol／資産の対応表を決めてから外部参照を再配線する。画像は既存hashを共有し、異なる内容の宣言で上書きしない。貼付先の中央・連続貼付offsetを適用するのは選択配置だけで、参照画面の図面座標を移動しない。

貼付先全体を検証してから一度の編集として確定する。現行画面を再利用した結果の自己参照・入れ子、Symbol定義への貼付、上限超過は拒否する。成功時は配置・取込画面・定義・資産をUndo1回で戻せる。失敗時は元Project・履歴を保持し、候補原本を回収する。

## 切り取りと非同期処理

画像原本があればsnapshotとleaseを確保し、利用者の操作中にClipboardItem書込を開始する。画像の有無は直下Imageではなくsnapshot全体の資産から判定する。書込が失敗した場合は切取元を削除しない。書込中に世代・画面・mode・revision・選択・未適用入力が変わった場合も削除を中止する。

貼付読取・原本の検証後にも既存のowner／revision／未適用入力を照合し、対象変更後の遅延応答を適用しない。認証やHub接続の変更は含めない。

`clipboard-dependencies.ts`は参照閉包の収集、`clipboard.ts`はsnapshot・envelopeの検証、`asset-clipboard.ts`はleaseと原本のencode／decodeを担当する。`editor/paste-handler.ts`は現行再利用・ID再発行・参照の再配線、`designer/controllers/clipboard.svelte.ts`はOS操作と非同期所有者を担当する。

`screen-view-clipboard.test.ts`は参照集約・現行再利用・削除後復元・内部ID・座標保持・自己参照／入れ子・余分な依存・機器関連付けの拒否を確認する。`asset-clipboard.test.ts`は背景だけの原本と古い資産の不取込、ブラウザはnative操作・別Project・背景cropと原本往復・Undo／Redo・書込失敗を確認する。
