## 保存と描画

Symbol配置のshapeへ必須の`colorMode: "monochrome" | "definition"`を追加する。`fill`は両モードで保存し続ける。

| モード     | 表示                                                             |
| ---------- | ---------------------------------------------------------------- |
| monochrome | 配置のfillで定義内の図形・文字・線・矢印を単色にする。現在の挙動 |
| definition | 定義内の各図形のfillで描く。配置のfillは保持し、表示には使わない |

新規配置はmonochromeを既定とする。複製・独立コピー・clipboardは元のモードとfillを保持する。definitionへ切り替えても配置の単色を捨てず、戻したときは以前のfillを使う。代表色の推測・テーマによる色変換・定義の書換えを行わない。

モードは配置ごとに独立する。定義内の色編集はdefinitionモードの全配置へ反映し、monochromeの色は維持する。hidden子は両モードで非表示を維持する。位置・サイズ・描画順・所属・Bindingを変えない。

Editor・表示プレビュー・ミニマップで同じ描画経路を使う。SymbolThumbnail／ObjectIconは種類を示すUIアイコンとしてmuted単色を維持し、実配色のプレビューとは扱わない。

## 単一選択の編集

Inspectorに「色の使い方：配置の単色／共有定義の色」を設ける。モードは独立したdraftフォームで明示適用し、未適用の切替を図面へ流さない。通常の名前・座標等とは既存draft guardで連携する。独立フォームにして、未確定のモードと数値の自動確定を混ぜない。

共有定義の色を使用中は配置の色入力を無効にし、定義で各図形の色を編集すると説明する。無効化した入力がFormDataへ入らない場合、他のプロパティ適用でfillを消したり文字列nullを保存したりしない。単色へ切り替えて適用した後、保持しているfillを通常どおり編集できる。

共有定義の編集画面にも、definitionモードには各図形の配色、monochromeには配置の単色が表示されることを示す。ロック中の配置のモード変更を防ぎ、共有定義を別途変更できる既存の境界は維持する。

## 複数選択の共通色

definitionモードのSymbolを含む場合は、現在の表示に定義色が含まれると示す。保存されたfillの一致だけで「現在の色が共通」と断定しない。

共通色フォームに「共有定義の色を使うSymbol N件を配置単色へ切り替える」チェックを追加し、初期OFFにする。指定色とチェックが揃うまで適用できない。色の指定だけでモードを自動変更せず、別の確認ダイアログも挟まない。

共通set-colorコマンドへ明示的な変換指定を追加する。definitionモードを含み、指定がない場合は全体を拒否する。指定した場合は全対象の色と対象Symbolのモードを同じコマンド・Undo1回で変更する。共有定義自体は変えない。ロック混在・参照切れ・不正色・不正指定は原子的に拒否する。非表示対象は件数を示して変更できる。

全対象が既に指定した色・モードならno-op。同じfillでもdefinitionからmonochromeへ切り替わる場合は履歴へ記録する。色・チェックの未適用入力は、他フォームと一括事前検証してから反映する。

## 提供段階と受入条件

0.8.0の自動移行は追加しない。既存0.1.0の移行経路は維持する。配置ごとの静的な配色であり、運転・停止・故障、通信品質、表示式や設備権限を意味しない。

- Rust／TS／共有Schemaで、Symbolだけに必須のenum、欠落・不正値・他図形への誤指定、JSON往復を検証する。
- 矩形・楕円・文字・線・矢印の定義色、単色化・元の単色への復帰、同一定義の配置ごとの独立、定義更新・hidden子を確認する。
- モード編集・共通色による明示変換、locked混在、無効なpatch・古い対象、同値no-op、他の未適用入力との事前検証を確認する。
- 複製・独立コピー・同一／別Projectへのclipboard・JSON・Undo／Redoでモードとfillを保持する。
- Editor／preview／minimap・両テーマ・狭幅・キーボードを確認する。UIアイコンの単色を実配色の確認と混同しない。

進捗・実画面は[開発計画](implementation-status.md)へ記録する。
