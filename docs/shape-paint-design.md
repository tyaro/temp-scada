# 矩形・楕円の塗りと枠線

状態: **Astraレビューに基づく次の実装仕様。未実装**。現行Projectは0.9.0。モデル追加時は0.10.0へ更新し、Rust／TypeScript／Schema／現行サンプル・新規生成を同期する。認証・設備操作・状態別表示を追加しない。

## 保存契約

矩形・楕円のshapeへ必須のpaintを追加する。既存object.fillは塗りの保存色として維持し、塗りを無効にしても捨てない。

```ts
paint: {
  fillEnabled: boolean;
  stroke: { color: string; width: number } | null;
}
```

枠線なしはnull、有効な線幅は0より大きく64以下。幅0を枠線なしの別表現にしない。色は既存の6桁HEX契約を共用する。他の図形へpaintを許可しない。新規配置は塗りあり・枠線なしとし、既存の外観を保つ。塗りも枠線もない形状を許容し、編集時の透明ヒット領域・レイヤーからの再選択で復帰できるようにする。visible=falseとは別の設定である。

## 操作

単一選択のプロパティに塗りの有無、塗り色、枠線の有無・色・幅をまとめる。無効な塗り色は保存値として示し、枠線の詳細は有効時だけ表示する。新たに枠線を有効にする際は既定色と幅をフォームに用意する。枠線なしへ適用した後の再有効化で以前の線色・幅を復元することは保証しない（nullとして保存する）。

paintは独立した明示適用のdraftフォームで扱う。数値入力のblurで塗り・枠線の有効化を先に確定しない。他の未適用入力と一括事前検証し、検証失敗やキャンセルで一部だけ変更しない。ロック、IME、Undo／Redo、同値no-opを共用する。複数選択の枠線一括編集は後続。

既存の共通色は、有効な塗りと有効な枠線の両方へ適用する。無効な塗りの保存色は変えず、無効な枠線を生成しない。塗りも枠線も無効の矩形・楕円を含む場合は全体を拒否して理由を示す。非表示の配置は従来どおり件数を示して明示編集できる。定義色Symbolの明示単色化は既存の確認フラグを維持する。

## 描画と外形

共有Symbolの単色モードは、有効な塗り・枠線の色だけを配置色で上書きする。線幅と有効／無効は共有定義を保持する。定義色モードは各図形の塗り・枠線をそのまま描く。Editor／preview／minimapで描画を共用する。

枠線は輪郭の中央へ描く。本体寸法をサイズ入力・ハンドル・将来の回転中心へ使い、枠線の半幅を含む外形を選択枠・範囲選択・整列へ使う。既存getBoundsの各呼出用途を確認し、本体寸法と描画外形を区別する。clipboardの貼付基準・中心配置も描画外形で一貫させる。枠線を変えて座標・本体寸法を自動変更しない。

Symbol配置の外形は定義viewportを基準とする既存契約を維持する。内部図形の枠線からviewBoxを自動拡張すると配置の縮尺が変わるため行わない。共有定義の編集で枠線が表示領域外へ出る場合は案内し、位置／寸法または定義表示領域の明示編集で解消する。

## 受入条件

- 共有Schema／Rust／TSで必須paint、型・未知属性・色・線幅の上下限、対象型、JSON往復を確認する。旧0.9.0は自動移行せず拒否し、既存0.1.0の移行は新規既定paintを補う。
- 塗りのみ／枠線のみ／両方／両方なし、保存色、無効項目の非適用、同値no-op、ロック・非表示、Undo／Redoを確認する。
- 複製・同一／別Project clipboard・Symbolの複製／独立コピーでpaintを保持する。
- 本体寸法と描画外形、整列・中心等間隔・範囲選択・貼付・移動／サイズ変更を確認する。Symbolはviewportを維持する。
- 両テーマ、狭幅、通常Enter・IME・未適用入力の保護、Editor／preview／minimapを実ブラウザで確認する。
