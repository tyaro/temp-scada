# 実線・破線・点線

文書の位置付け: **採用済み設計・導入時の実装記録。文中の旧版・件数・当時の未実装表記は記録時点のもの。** 現在の対応範囲と保存契約は[実装状況](../../project/implementation-status.md)を正とする。

2026-10-20。基準は[描画拡張の設計](../proposals/scada-graphics-runtime-extension-design.md)。線・配管と矩形／楕円の枠線に共通の線種を追加する。α・gradient／pattern・画像は後続とし、本工程で実装済み扱いにしない。

## 保存・描画

Project／最小Runtimeは0.13.0。PolylineのshapeとShapePaint.strokeへ任意の `lineStyle: solid | dashed | dotted` を追加する。省略は実線で、現行サンプル・生成した配置・0.1.0移行は省略形を利用する。0.12.0は自動移行せず拒否する。

| 線種 | SVGのdash配列  | 端の形 |
| ---- | -------------- | ------ |
| 実線 | なし           | round  |
| 破線 | 線幅×4、線幅×2 | butt   |
| 点線 | 0、線幅×2      | round  |

間隔はdesign unitで線幅に比例し、回転・Symbol内の縮尺と共に変換する。矢印は独立した実線のpolygonを保持する。線種だけではbounds・頂点・位置・本体寸法・塗り・選択を変更せず、選択用の透明なhit領域は連続したままにする。既存の保守的な線幅・矢印のboundsを共用する。

Editor／表示プレビュー／ミニマップ／Symbol・サムネイルは同じPrimitiveを使う。Symbolの単色／定義色は線種を変えない。

## 入力・履歴

単一の線・配管は既存のオブジェクトフォームで線種を選び「変更を適用」。矩形／楕円は「塗りと枠線」の線種を明示適用する。線幅のEnter／blur確定だけで他の未適用スタイルを確定しない。既存のEsc・IME・draft guardを維持する。

複数選択では現在の共通線種／混在を示し、適用欄は「変更なし」から始める。実線を選ぶ操作は明示解除で、空欄とは分ける。線幅だけ／色だけの変更では線種を保持する。ロック混在・異種選択は全体を拒否し、非表示の対象は件数を示して明示変更できる。

枠線なしを含む選択へ新設する場合は、従来どおり「あり」と色・幅を明示する。線種の未指定は新設分だけ実線となり、既存枠線の線種は保つ。「なし」と線種の同時指定は拒否する。適用後の一括入力と「指定を解除」は未指定へ戻し、古い線種を次の対象へ適用しない。

複数変更は1回のUndo。省略された実線への実線指定と、JSONで明示された実線への無変更適用は履歴を増やさない。描画用dash配列は保存せず、プリセットと線幅から求める。

## 受入

Rust／TypeScriptの共通fixtureで列挙値・省略・不正型と両所有先を検証する。ブラウザで両テーマ、単独／一括、Undo／Redo／JSON、枠線新設・解除、ロック／非表示、draft、幅・色・回転、Symbol両色モード、点線の隙間での選択、実線の矢印とミニマップを確認する。
