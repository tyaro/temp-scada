# 配管の分岐の点

作成: 2026-11-13（日本時間）。状態: **実装済み（フロー図 段階1-E）**。計画は[目標のフロー図と現状の差分](../editor/flow-diagram-gap-2026-11-12.md#53-段階1-bf)の E。

## 目的

T 字に分かれる配管の分岐を、交差（つながっていない）と見分けられるようにする。系統図の慣習どおり、つながっている所に塗りの円を描く。

## 保存しない

線同士の接続は保存モデルにない（[接続追従](../editor/connection-follow-design.md)。Polyline の端は Symbol にだけ接続する）。分岐の点は保存せず、描画時に画面の配置から計算する。schema・Rust・schemaVersion は変えない。

## 対象

- 同じ画面の、画面直下の Polyline 同士。表示されているもの（`visible !== false`。非表示のフォルダー・レイヤーは配置の `visible` に反映される）だけ。
- Symbol 定義の中の線（部品の線画）は対象外。Symbol 定義を編集する Renderer でも描かない。
- 頂点が 2 つ未満の Polyline は除く。
- 座標は回転・反転を適用した world 座標（`rotation.ts` の `objectToWorld`、描画・接続と同じ変換）。

## 点を描く条件

許容距離 `junctionTolerance` = 0.5（画面座標）。

1. **T 字**: ある線の始点か終点が、別の線の**途中**に 0.5 以内で乗る。途中とは、その線の始点・終点から 0.5 より離れた位置で、途中の頂点（曲がり角）も含む。
2. **集まり**: 3 つ以上の端点が 0.5 以内に集まる（近い端点を連鎖でまとめる）。1 本の線の両端が同じ位置にある場合も 2 つと数える。
3. **描かない**: 2 つの端点がつながるだけ（継ぎ足し）。線同士が端点以外で交わるだけ（交差。またぎは別の区切り）。同じ線の端点が自分自身の途中に乗る場合も見ない。

許容値の根拠: 頂点は通常、格子（1 単位以上）に合わせて置くので、1 単位ずれた端点は「つながっていない」と扱いたい。一方、回転・反転の三角関数で生じる誤差（1e-12 程度）や小数の入力の丸めは吸収したい。0.5 は格子 1 単位の半分で、両方を満たす。

## 見た目

- 塗りの円（`<circle data-line-junction>`）。
- 色・不透明度は通る側の線（T 字のとき。通る線が複数なら後に描かれる線）。集まりのときは関わる線のうち後に描かれる線。画面直下の線は状態の色を持たないので、色は配置の `fill`、不透明度は `compositedOpacity` と同じ。
- 直径は関わる線の最大の線幅の 3 倍、最小 6（`junctionDiameter`）。太い枝が細い本管に付いても、枝の太さを覆う。
- 位置は T 字なら通る線の上の最も近い点（線の中心に乗る）、集まりなら端点の平均。
- 重なり順は、関わる線のうち後に描かれる線（`order` が大きい線）の直後。後の線に隠れず、その後の配置には隠れる。

## 選択・hit・外接矩形

分岐の点は描画だけにし、`pointer-events="none"` とする。選択・hit・外接矩形（`getLayoutBounds`）・整列・接続点には含めない。点は他の配置の組合せで現れたり消えたりするので、1 つの配置の大きさに入れると、関係のない編集で選択枠や整列が変わってしまうため。点は線の中心から最大で線幅の 1.5 倍（最小 3）までなので、はみ出しはわずかである。

## 描画の共通化

`line-junction.ts` の `screenJunctions(objects)` が、Polyline の id ごとに「その直後に描く点」を返す。`Renderer`（Designer の編集・表示プレビュー。ドラッグ中はプレビューの位置で計算し、点も追従する）、`ScreenPainting`（画面の小窓）、`ScreenView`（埋め込みの画面）が同じ関数と `LineJunctionDots.svelte` を使い、各配置の `<g>` の直後に置く。

## 性能

- 計算は `$derived` で、画面の配置（またはドラッグのプレビュー）が変わったときだけ行う。読取の更新では計算しない。
- 線分を 64 単位の格子に入れ（`SegmentIndex`）、端点の格子の線分だけを調べる。端点同士は格子の近傍 3×3 だけを見る。全組合せの O(n²) にしない。1000 本の配管の試験で 200ms 未満（実測は数 ms）。

## 後の拡張

交差のまたぎは、同じ `worldLines`（world 座標の線）と `SegmentIndex`（線分の格子）を使ってこのモジュールに足す。
