# 時計（clock 図形）

作成: 2026-11-13（日本時間）。状態: **実装済み（フロー図 段階2-B）**。計画は[目標のフロー図と現状の差分](../editor/flow-diagram-gap-2026-11-12.md#543-pr-の区切り)の 2-B。

## 目的

画面の隅に「2026/01/05 03:04:09」のような現在の日時を出す。Text にタグを割り当てる形では端末の時刻を出せないので、専用の図形にする。

## 保存の形

配置の `shape` に `type: "clock"` を加えた。画面にも共有Symbolの定義にも置ける（primitive）。配置は幅・高さを持ち、回転できる。

| 項目      | 型                       | 意味                                                                              |
| --------- | ------------------------ | --------------------------------------------------------------------------------- |
| `format`  | `date` `time` `dateTime` | 日付だけ・時刻だけ・日付と時刻。                                                  |
| `seconds` | `true`（任意）           | 時刻に秒を付ける。付けないときは持たない（`false` は保存しない。schema で拒否）。 |
| `style`   | 文字書式                 | `fontSize`・`fontWeight`・`align`。Table と同じく Text の `wrap` は持たない。     |

文字色は配置の `fill`、その不透明度は `colorAlpha`（Text と同じ）。タグ・slot・書式は持たない。

- 文字を含むので、Text と同じく反転（`flipX`／`flipY`）できない（schema・`canFlip` で拒否）。反転した Symbol 配置の中でも `readableChild` で読める向きに描く。
- schemaVersion は 0.37.0 を据え置いた。旧形式の読込・移行はない。

## 表示の規則

- 純関数 `clock-format.ts` の `formatClock(shape, at)`。`at` は `Date` か epoch ms で、**端末のローカル時刻**として書式にする。
  - 日付は `YYYY/MM/DD`、時刻は 24 時間のゼロ埋めで `HH:mm`、秒ありは `HH:mm:ss`。日付と時刻は半角スペースで続ける（`2026/01/05 03:04`）。
  - 日付だけの書式では `seconds` は効かない。無効な日時は空の文字にする。
- `ClockPrimitive.svelte` が `TextPrimitive`（Text と同じ描画・はみ出しの省略）に文字を渡す。文字サイズ・色・揃えは Text と同じ。
- 更新は共有タイマー `clock-ticker.svelte.ts`（`createSubscriber`）。時計が描かれている間だけ 1 つの `setTimeout` を回し、秒の境目ごとに全時計を更新する。時計が 1 つも描かれていなければタイマーは止まる。
- 編集中もプレビューも同じ表示。Hub の時刻・時刻帯の指定は扱わない。

## 編集

- 追加: 部品パネル（オブジェクトの分類）・お気に入り・右クリックの挿入・メニューの「時計を追加」。既定は 220×32、日付と時刻（秒なし）、文字サイズ 18・標準・左揃え。
- Inspector（「変更を適用」か Ctrl／⌘＋Enter で確定）: 「表示」（日付・時刻・日付と時刻）、「秒」（出さない／出す）、文字サイズ・文字の太さ・文字揃え。文字色は共通の「文字」の色。
- 編集コマンドは `update` の `clock`（`type` 以外の全項目を置き換える。`seconds` は `true` のときだけ保存）。

## 後続・未対応

- 曜日・和暦・12 時間表示・任意の書式文字列・時刻帯の指定は持たない。
- Hub の時刻を出す表示は扱わない（端末の時刻だけ）。
