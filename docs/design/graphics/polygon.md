# 塗りつぶした多角形

作成: 2026-11-18（日本時間）。状態: **P2（画面の上での頂点のドラッグ）実装済み**（挿入の初期形・Symbol 定義のサンプル・操作ガイドは未実装、P3）。起票は Issue #260。決めること 4 点は 2026-11-18 にユーザーが推奨案を選んだ。同日、Fable の通しレビュー（P1 3 件・P2 7 件・P3 5 件）を反映した。

## 目的

塗りつぶした任意の形（直線の辺だけの多角形）を、画面の直下と Symbol 定義の中に置けるようにする。これで、ホッパー・シュート（台形）、サイロ・サイクロン（円筒＋円錐）、破砕機の外形（切り欠きのある形）、傾斜コンベヤの帯（平行四辺形）、行き先の札（片側が矢じり形の五角形）、フロー図のひし形を、利用者がカスタム部品として描き、機器に結び付けて状態色で塗り替えられる。

参照にした実プラントの画面は、リポジトリにも文書にも載せない（画像・配置・名称を書かない）。

## 決めたこと

| 項目          | 決定                                                                                              | 理由                                                                                                                                                      |

| schemaVersion | 0.37.0 のまま                                                                                     | 任意の shape の追加。リリース前の Project は後方互換を保証しない方針（AGENTS.md、2026-10-18）。警報の小札・帯・一覧の窓を足したときも据え置いた           |

schemaVersion を据え置くので、polygon を含む Project を同じ 0.37.0 の古い build（host・runtime を含む）で開くと、版の案内ではなく schema の検証エラーで拒否される。方針どおりとし、移行の処理は作らない。

## 保存契約

配置は矩形・楕円と同じ定義（共通 schema の `primitive`）に入れ、`shape` の種類を 1 つ足す。

```ts
shape: {
  type: "polygon";
  points: { x: number; y: number }[]; // 3〜64 点。枠に対する割合
  paint: ShapePaint;                   // 矩形・楕円と同じ
  stateColor?: StateColor;             // 矩形・楕円と同じ
}
```

- 頂点の順に辺を結び、最後の点から最初の点へ閉じる。閉じる点を重ねて保存しない。
- 頂点 (u, v) の配置の中の位置（以下「実寸の頂点」）は (u × width, v × height)。回転・反転は矩形・楕円と同じく枠の中心を基準に、配置の `rotation`・`flipX`・`flipY` で行う。回転・反転・枠のリサイズ・幅／高さの数値入力・複製・貼付けは `points` を変えない。
- root の `fill`・`colorAlpha` は矩形・楕円と同じく禁止する（schema の `allOf` の対象の列に `polygon` を足す）。
- 塗りの規則は `nonzero` に固定し、保存しない。自己交差（8 の字など）は拒否しない。頂点をドラッグする途中で一時的に交差しても編集を止めないためと、Rust と TypeScript で交差判定の誤差を揃える費用を避けるため。

### 枠と頂点をぴったり合わせる

頂点の外接矩形を、常に枠そのものとする。保存された頂点は次をすべて満たす。

- 各座標は有限で 0 以上 1 以下。
- x の最小が 0、最大が 1。y の最小が 0、最大が 1（いずれも厳密に等しい）。

こうすると、選択枠・範囲選択・整列・貼付けの基準が矩形・楕円と同じ枠で済み、「枠の中の余白」という状態が生じない。

### 枠の作り直し（P1 の純関数）

頂点を変える編集（Inspector の頂点の欄、P2 のドラッグ）は、すべて 1 つの純関数を通す。

- 入力: 今の配置（`x`・`y`・`width`・`height`・`rotation`・`flipX`・`flipY`・`points`）と、編集後の実寸の頂点の列（今の枠の左上を原点とする配置の中の座標。頂点数は変わってよい）。
- 出力: 新しい `x`・`y`・`width`・`height`・`points`。または拒否の理由。
- 手順:
  1. 実寸の頂点の外接矩形（最小 m、大きさ w′ × h′）を求める。w′ か h′ が 1 未満なら拒否する（枠のハンドルの最小 1 と揃える。割合の式が 0/0 にならないよう、割合を作る前に判定する）。
  2. 割合を (p − m) / (w′, h′) で作る。この式は最小の点で 0、最大の点で 1 を正確に返す（IEEE 754 で x / x = 1）。
  3. 外接矩形が今の枠と同じ（m = 0 かつ w′ = width かつ h′ = height）なら、触っていない頂点の u・v は今の値をそのまま残す。(u × w) / w = u は浮動小数点で保証されないので、作り直すたびに 1ulp ずつずれるのを防ぐ。実装（P1c）は軸ごとに判定し、x の範囲（m.x = 0 かつ w′ = width）が同じなら u を、y の範囲が同じなら v を残す。触っていない頂点は入力で `{ keep: i }` と示す。
  4. 位置を補正して、動かしていない頂点の画面上の位置を保つ。今の中心を c = (width / 2, height / 2)、新しい中心を c′ = (w′ / 2, h′ / 2)、M を「反転してから回転」の変換（`rotation.ts` の `placementVector`）として、**(x′, y′) = (x, y) + c − c′ + M(m + c′ − c)**。この式は、どの頂点を動かしたかに依らないので、頂点数が変わる編集にも使える。`resizeRotated` と同じ形になる。
  5. 下の退化の規則で検査し、当たれば拒否する。

`replaceRotatedVertex`（Polyline 用）は流用しない。polygon は `width` と `shape.points` の両方を持つので、型の上では枠の配置にも線にも当てはまり、`rotationPivot` が `"width" in object` を先に見るため、補正が 0 のまま型検査を通ってしまう。同じ理由で、`objectToWorld` などの幾何の関数へ割合の点をそのまま渡さない。実寸の頂点を返す関数（`polygonLocalPoints`）を 1 つ置き、幾何の関数へは必ずそれを通す。

### 退化した形の拒否

次のどれかに当たる形は、保存・読込・編集の確定で拒否する。Rust（`scada-model`）と TypeScript（`project.ts`）で同じ規則・同じ演算順にする（Rust で `mul_add` を使わない）。

1. 頂点が 3 未満、または 64 を超える。
2. 隣り合う 2 点が同じ（最後と最初の組も含む）。
3. すべての頂点が一直線上にある。外接矩形が 0〜1 にぴったり合うので、一直線になりうるのは 2 本の対角線上だけ。判定は「全点で |u − v| < 1e-9」または「全点で |u + v − 1| < 1e-9」。
4. 編集の確定では、上の枠の作り直しの 1（実寸の幅・高さが 1 未満）も拒否する。保存・読込では既存の schema の width・height > 0 だけを見る。

これらを通っても、塗りの面積が 0 の形は残りうる（例: (0,0), (1,0), (1,1), (1,0) のように、離れた頂点が重なり辺が往復する形）。これは拒否しない。塗りが見えなくても選べるよう、当たり判定に透明な線を付ける（下の「当たり判定」）。

## 描画

- `Primitive.svelte` で SVG の `<polygon>` を描く。頂点は描画のときに実寸へ直す。`viewBox` の伸縮で描かないので、枠線の幅は縦横で歪まない。
- 塗り（単色・線形／放射グラデーション・パターン）・枠線（色・幅・線種・α）・不透明度・状態色は、矩形・楕円の処理を共用する。グラデーションは既存どおり `objectBoundingBox`（＝枠）を基準にする。
- 枠線は輪郭の中央に描く。角は `stroke-linejoin: miter`、`stroke-miterlimit: 4`（SVG の既定）。
- Designer・表示プレビュー・運転表示・画面の小窓・埋め込み・ミニマップ・お気に入りのアイコンで同じ部品を通す。
- Symbol の単色モードでは、矩形・楕円と同じく、有効な塗り・枠線の色だけを配置色で上書きする。

### 外形

- 本体の寸法（サイズ入力・ハンドル・回転の中心）は枠。
- 描画の外形（選択枠・範囲選択・整列・貼付けの基準）は、`getLocalBounds` で polygon だけ次の和の外接矩形とする。矩形・楕円の「線幅の半分を足す」では、鋭い角の miter の先端が外へ出るため。
  - 各辺を、その法線方向に ±（線幅 / 2）ずらした長方形（180° の頂点＝辺の途中の点でも、ここで法線方向の張り出しが入る）。
  - 各頂点の miter の先端。角の内角を θ として、比 1 / sin(θ / 2) が 4 以下の角だけ（4 を超える角は SVG が bevel に切り替えるので、辺の長方形に含まれる）。
  - 隣の点とほぼ同じ方向に折り返す角（θ が 0 に近い）は、比が 4 を超えるので bevel 側になる。limit の境目では外形が線幅の 2 倍から半分へ飛ぶ。これは SVG の描画と一致させるためで、不具合ではない。
  - 点線は長さ 0 の dash を丸い端点で描くので、頂点に乗る点が全方向に線幅の半分はみ出す。点線のときは、頂点の外接矩形を線幅の半分ずつ広げた矩形も和に入れる（PR #282 の Codex 指摘）。破線は butt なので上の和に収まる。
- 整列・範囲選択・貼付けは `getBounds` 経由で `getLocalBounds` を使うので、ここを変えれば揃う。Symbol 配置の外形は定義の viewport を基準とする既存契約のまま。
- Symbol 定義の枠から枠線がはみ出すときの警告（`strokeOverflowIds`）の対象に polygon を足す。Symbol は入れ子の svg で描くので、鋭い角の先端は黙って切れるため。

### 当たり判定

Designer の当たり判定は、今は Polyline 以外すべて `getLocalBounds` の透明な矩形で行う（楕円も矩形で当たる）。polygon はこれと分け、Polyline の分岐と同じ場所に、形そのものの当たり判定を新しく置く。

- 透明な塗りの `<polygon>` と、同じ輪郭の透明な線（幅は Polyline と同じ `max(12, 線幅 + 8)`）。塗りも枠線もない形・面積 0 の形・細い三角形も、輪郭の近くで必ずつかめる。
- 三角形の枠の外側の隅をクリックしたときは、その下の配置が選べる。密に重なるフロー図で、隣の図形を選びにくくしないため。楕円とは挙動が変わる（楕円は矩形のまま）。
- 機器リンクの当たり判定（運転表示側）も同じ形にする。
- 範囲選択は描画の外形で判定する（矩形・楕円と同じ）。

## 編集

- **挿入**: 部品パレット・挿入メニュー・お気に入り（`favorites.ts`・`FavoritesDock`・`ObjectIcon`）に「多角形」を足す。初期形は三角形（(0.5, 0), (1, 1), (0, 1)）、枠の大きさは矩形の挿入と同じ。初期形の種類（台形・ひし形・札など）は段階 P3 で足す。
- **頂点の移動（P2）**: 選択中の多角形の頂点にハンドルを出し、ドラッグで動かす。コマンド `move-vertex` を polygon にも広げる。`point` の単位は「今の枠の左上を原点とする実寸の頂点」と契約に書く。1 回のドラッグを 1 回の元に戻す単位にする。ドラッグ中は外接矩形・退化を検査せずに形を見せ、離したときに枠の作り直しを通す。拒否されたら元の形に戻し、理由を通知する（Polyline の端点の接続の拒否と同じ見せ方）。実装（P2）では、頂点のハンドルは枠の角のサイズ変更の四角が見えてつかめるよう Polyline より小さい白抜きの丸にし、重なる所では頂点を優先する。方向キーでも 1（Shift で 10、グリッド吸着中は次のグリッド線）動かせる。吸着は画面上の座標で行い、Alt で外す（Polyline と同じ）。
- **頂点の追加・削除（P1）**: Inspector の「頂点（x,y を 1 行ずつ）」の欄で行う（Polyline と同じ欄の形）。欄の値は今の枠の左上を原点とする実寸で示し、適用時に枠の作り直しを通す。欄は行ごとに今の値と比べ、文字が変わった行だけを置き換える（表示の丸め・全桁表示の往復で、触っていない頂点を動かさない）。拒否は理由を欄の下に出し、Project を変えない。欄は今の枠を原点に書くので、同じ確定で位置・サイズの欄も変えた入力は拒否する（P1c）。
- **共通の操作**: 移動・回転・反転・複製・配列複製・整列・等間隔・ロック・表示切替・不透明度・重なり順・グループ・フォルダー・clipboard（同じ／別の Project）は、矩形・楕円と同じ扱い。
- **面の図形の判定を 1 つにまとめる**: 矩形・楕円の分岐を、面の図形かを返す関数（TypeScript・Rust にそれぞれ 1 つ）へまとめてから polygon を足す。
  - TypeScript（約 60 か所）。たとえば `project.ts` の塗りの検証、`opacity.ts`、`state-color.ts`、`selection-paint-alpha.ts`、`SelectionOutline.svelte`、`placement-handler.ts`、`commands.ts`、`forms/shape-paint.ts`、`forms/state-color.ts`。
  - Rust（`scada-model/src/lib.rs` の模様の太さ・放射／線形グラデーションの有限性の検証と、その試験の列挙）。ここに足さないと、TypeScript が拒否する塗りを Rust が通す。

## 状態色

矩形・楕円と同じ `stateColor` の規則（有効な単色塗りのとき）。Symbol 定義の中では slot の状態の文字、画面の直下では bool 表示の Text を配色元にする。`state-color.ts` の参照・塗り条件の検証と、`remapStateColor` の対象に polygon を足す。Rust の状態色の検証は、面の図形の判定を通せば polygon も塗りの分岐に入る。

## 対象外

- 曲線の辺（円弧・ベジェ）、穴のある形、自己交差の塗りの規則の選択、角の丸め。
- 多角形の辺への配管の接続。接続は Symbol 配置の枠の接続点のまま。多角形を含む Symbol 定義を配置すれば、その配置の枠に配管をつなげる。
- 配管の分岐の点・交差のまたぎの対象にしない（Polyline だけ）。
- 画面の上での頂点の追加・削除（辺のダブルクリックなど）。Polyline にもないので、両方に入れるかを別に決める。
- 内蔵部品（`symbol-library.json`）へホッパー・サイロなどを足すこと。別の区切りで決める。

## 受入

- 多角形を画面と Symbol 定義に置き、塗り・枠線・状態色が矩形・楕円と同じ規則で出る。Symbol 配置の単色モードで、有効な塗り・枠線だけが配置色になる。両テーマの e2e。
- 頂点の移動・追加・削除ができ、元に戻す・やり直すが 1 操作ずつ効く。
- 枠の作り直しの契約試験: 回転（0°・90°・任意角）× flipX × flipY の組合せで、動かしていない頂点の画面上の位置が許容差 1e-9 以内で変わらない。外接矩形が変わらない編集では、触っていない頂点の u・v がビット単位で変わらない。
- 枠のリサイズと、幅・高さの数値入力で `points` が変わらない。
- 保存して読み直しても形が変わらない（JSON と package の往復、複製、コピー・貼付け）。
- Rust と TypeScript が同じ契約ケースを通る。
  - 受け入れ: `-0`・`1.0`・`1e0` の座標（0・1 と等しい）、自己交差、面積 0 だが一直線でない形。
  - 拒否: 頂点 2 点・65 点、範囲外・非有限の値、外接矩形が 0〜1 にぴったり合わない、隣り合う同じ点、最後と最初が同じ、2 本の対角線それぞれでの一直線、root の `fill`、polygon で無効な塗り（模様の太さ・グラデーションの値）。
- 編集の確定で、実寸の幅・高さが 1 未満になる頂点の編集（水平・垂直に一直線）を拒否し、Project を変えない。
- 外形の試験ベクトル: miter の limit の境目の角、180° の頂点、ほぼ折り返す角。鋭い角の多角形で、選択枠が枠線の先端を含む。
- Symbol 定義の枠から角の先端がはみ出すと警告が出る。
- 塗りも枠線もない多角形を、輪郭の近くのクリックで選べる。三角形の空いた隅をクリックすると、下の配置が選ばれる（e2e）。
- ホッパー（台形）・サイロ（円筒＋円錐）・行き先の札（五角形）を、多角形と既存の図形だけで Symbol 定義として作れる（P3）。
