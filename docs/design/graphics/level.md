# 液位（level 図形）

作成: 2026-11-12（日本時間）。状態: **実装済み（フロー図 段階1-C）**。計画は[目標のフロー図と現状の差分](../editor/flow-diagram-gap-2026-11-12.md#53-段階1-bf)の C。

## 目的

槽・塔の液位のように、数値に比例して塗る棒を描く。欠測や範囲外の値を、実在の液位に見せない。

## 保存の形

配置の `shape` に `type: "level"` を加えた。画面にも共有Symbolの定義にも置ける。

| 項目          | 型                | 意味                                                                        |
| ------------- | ----------------- | --------------------------------------------------------------------------- |
| `direction`   | `"up"`／`"right"` | 塗りの伸びる向き（下から上、左から右）。                                    |
| `min`・`max`  | 数値              | 下限と上限。`min < max` が必要（schema では書けないので Rust・TS で検査）。 |
| `background`  | 色（任意）        | 塗られていない部分の色。ないときは透明。                                    |
| `binding`     | タグ（任意）      | 画面の液位が読むタグ。Text と同じ形。                                       |
| `slotBinding` | slot 名（任意）   | 共有Symbol内の液位が読む slot。number の読取slotだけ。                      |

- 塗りの色は配置の `fill`（Text の文字色と同じ欄）。色の不透明度（`colorAlpha`）は塗りにだけ効き、地には効かない。
- `binding` と `slotBinding` は同時に持てない。Symbol 定義内の直接のタグ、画面上の slot は、Text と同じく拒否する。
- 結合は Text と同じ項目名なので、Rust の `text_bindings`（読取の購読）、タグの参照一覧・一括置換、slot の使用箇所（slot の改名・型変更の保護）に液位も入る。
- schemaVersion は 0.37.0 を据え置いた。旧形式の読込・移行はない。

## 表示の規則

`level.ts` の `levelFromReading`（タグ）と `levelFromSlot`（slot）が表示を決め、`Primitive.svelte` が描く。

| 状態                                                 | 塗り | 印                                                       |
| ---------------------------------------------------- | ---- | -------------------------------------------------------- |
| Good で範囲内                                        | 比例 | なし。SIM の値は塗りを薄くし、塗りの色の破線枠を付ける。 |
| Good で範囲外                                        | なし | 橙（`#f59e0b`）の枠と、はみ出した側の端の三角。          |
| 未接続・未解決・値が不正・更新停止・不良・未割付など | なし | 灰（`#9ca3af`）の破線枠。                                |

- 範囲の端（`min`・`max` ちょうど）は範囲内（空・満）。範囲外を端に丸めて塗ることはしない。
- 比率は `levelFraction` で求める。上限と下限の差が有限の数を超える（±`Number.MAX_VALUE` 付近）ときだけ、両方を半分にしてから差をとる。
- `<title>` に「液位 · タグ名（slot 名） · 値（範囲）」または欠測の理由を書く。描画の `g` は `data-level-state`（`good`／`low`／`high`／`unavailable`）を持つ。
- 数値の文字は液位に含めない。値を出すときは、[数値の書式](numeric-format.md)を付けた Text を重ねる。

## 編集

- 追加: 部品パネル・右クリックの挿入・メニューの「液位を追加」。既定は 40×120、下から上、0〜100、地 `#1e293b`。
- Inspector: 向き・下限・上限・地（色で塗る／透明）と地の色。画面ではタグ（候補からの選択も可）、定義では number の読取slotを選ぶ。「変更を適用」で確定する。
- 編集コマンドは `update` の `level`（向き・下限・上限・地）と、Text と共通の `binding`・`slotBinding`。

## 後続・未対応

- 上限・下限の警報色（H／L の帯）、目盛り、下向き・左向きは持たない。
- 槽の形（丸底など）に沿った塗りは持たない。槽の図形の上に重ねて使う。
- Tauri 実機・実Hub での表示は未確認。
