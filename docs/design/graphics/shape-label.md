# 図形の中の文字

作成: 2026-11-20（日本時間）。状態: **設計のみ（未実装）**。起票は Issue #305。決めること 6 点のうち 5 点は 2026-11-20 にユーザーが推奨案を選んだ（下表）。保存の形（決めること 2）は Issue の案をそのまま採る。同日、Fable の通しレビュー（P1 2 件・P2 9 件・P3 7 件）を反映した。

## 目的

フロー図の「形＋中の文字」の箱（工程の箱・判断のひし形・手入力の箱・端子）を、1 配置のまま置いて文言を入れられるようにする。今は図形と Text の 2 配置を置き、大きさと位置を揃え、グループにしている。立上／立下のシーケンス画面では 1 画面に 50〜80 個並ぶので、この手数を減らす。

参照にした実プラントの画面は、リポジトリにも文書にも載せない（画像・配置・名称を書かない）。

## 保存契約

矩形・楕円・多角形（`isAreaShape` が真の shape）にだけ、任意の `label` を足す。

```ts
label?: {
  text: string;     // 正規化の後で 1〜1000 文字。改行は LF
  style: TextStyle; // Text と同じ（fontSize・fontWeight・align・wrap?）
  color: string;    // $defs/color（"#rrggbb"、大文字も可）。枠線の色と同じ
};
```

- schema は `$defs/shapeLabel` を 1 つ作り、矩形・楕円・多角形の 3 つの枝から参照する。`text`・`style`・`color` はすべて必須、`additionalProperties: false`（`label` の中・`style` の中とも未知の項目は拒否）。`label: null` は拒否する（省くことで「無し」を表す）。
- **改行の正規化**: 読込時の `normalizeProjectText`（TypeScript の `project.ts`、Rust の `scada-model`）を `shape.label.text` にも広げ、Text と同じく CR・CRLF・U+2028・U+2029 を LF に直してから schema にかける。schema の `not pattern`（`[\r\u2028\u2029]`）は Text と同じく正規化の後の検査として置く。文字数の上限 1000 と空の判定も正規化の後に行う。文字数の数え方は Text の `maxLength` と同じ（JSON Schema の数え方。Rust と TypeScript で揃うことをサロゲートペアの契約ケースで確かめる）。
- **空の判定**: 正規化の後で厳密に `""` のときだけ拒否する（`minLength: 1`）。空白だけ・改行だけの文言は、Text と同じく trim せずに残す。空の `label` という状態は作らない。Inspector で文言を空にして確定したら `label` ごと消す。
- `style` は schema の `$defs/textStyle` を参照する。`wrap` を省いたときは Text と同じく `none`。
- `color` に α は持たない。配置の `opacity` は文字にも効く。
- root の `fill`・`colorAlpha` は、`label` があっても今までどおり面の図形では禁止のまま。文字色は `label.color` だけが持つ。
- 反転の拒否の `allOf`（Text・表・時計の列挙）は変えない。`label` を持つ面の図形は反転できる（決定 4）。
- 文字にタグ・slot・機器の属性は結合しない。`label` に `binding`・`slotBinding`・`equipmentProperty`・`format`・`stateColors` は置けない。
- 画面切替ボタンの `shape.label` は文字列で、名前が同じでも別の型。`label` を見る処理は shape の種類で分ける。
- Rust（`scada-model`）と TypeScript（`project.ts`）で同じ検査にし、共通の契約ケース `examples/shape-label-cases.json` を両方が読む。

### 新しく作るときの既定

Inspector で文言を入れて `label` を作るとき、書式の欄の値を使う。欄は `label` が無い間も既定値を表示し、入力もでき、文言と同じ確定で一緒に入る。

| 項目       | 既定                                                                                                                                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| fontSize   | 16                                                                                                                                                                                                                                    |
| fontWeight | `normal`                                                                                                                                                                                                                              |
| align      | `center`                                                                                                                                                                                                                              |
| wrap       | `word`（箱の中の文言は折り返すのが普通のため。保存では省かずに書く）                                                                                                                                                                  |
| color      | 塗りが有効な単色なら、`#ffffff` と `#0f172a` のうち、塗りの色とのコントラスト比（WCAG の相対輝度の式、塗りの α は見ない）が大きい方。同じ比なら `#0f172a`。それ以外の塗りや塗り無しは、Text の挿入と同じ `canvasColors(背景).newText` |

既定値は 1 か所（`shape-label.ts` の定数と関数）にまとめる。

## 描画

### 文字の領域

文字は形ごとに決まる矩形（文字の領域）の中に、Text の複数行の経路と同じ規則で描く。領域の中心は枠の中心。

| 形     | 文字の領域                                                                           |
| ------ | ------------------------------------------------------------------------------------ |
| 矩形   | 枠そのもの                                                                           |
| 楕円   | 内接する矩形（幅 `width / √2`、高さ `height / √2`）                                  |
| 多角形 | 枠そのもの（ひし形などでは角の近くに文字がかかりうる。大きさは利用者が枠で合わせる） |

- `MultilineTextPrimitive` を領域の幅・高さで呼び、`<g transform="translate((width − 領域の幅) / 2, (height − 領域の高さ) / 2)">` で包む。左右の余白 2px・行の高さ・縦の中央揃え・左右揃え・折返し・高さ不足の省略・幅不足の表示は、この部品の中の規則（領域の内側で取る）のまま。
- 1 行・折返し無しの文言でも同じ部品で描く。Text の 1 行の経路（`TextPrimitive`・`fitText`）とその Quality・SIM の規則は持ち込まない。比べる相手は「複数行の Text の経路」。
- 枠線の幅は領域から引かない。太い枠線の上に文字がかかるのは、Text を図形に重ねた今の見た目と同じ。
- 文字は塗りと枠線の上に描く（同じ配置の中で最後）。
- ひし形では折返しの幅が枠の幅なので、左寄せは形の外から始まる。操作ガイドとサンプルでは、ひし形は中央寄せにして枠を文言より広めに取ると書く。

### 回転・反転

- 回転: 文字は形と一緒に回る（Text の配置の回転と同じ）。`rotation` が 180° 付近で逆さまになるのは Text と同じく利用者の選択とする。
- 反転: 形は配置の `flipX`／`flipY` で鏡になる。文字は文字の領域の中心のまわりで鏡を打ち消して、読める向きで描く。領域の中心は枠の中心なので、打ち消しても位置は変わらない。`align: "left"` の文字は、反転しても左寄せのまま（鏡で右寄せにしない）。
- `flipX` と `flipY` の両方が真の配置は、形は 180° 回したのと同じに見えるが、文字は正立のまま（両軸とも打ち消すため）。`rotation: 180` との違いは意図どおりとする。
- 反転と回転の組合せ: 親が flipX の Symbol の中で子に `rotation: 30` があると、文字は鏡を打ち消した後に画面上で −30° 傾いて見える（鏡文字にはならない）。親の鏡が子の回転の向きを逆にするためで、Symbol の中の Text と同じ結果として意図どおりとする。
- **どこで計算するか**: `readableChild` は変えない（矩形を変えないことを `flip.test.ts` が固定している）。`rotation.ts` に純関数 `labelMirror(object, parent?) → { flipX: boolean, flipY: boolean }` を足す。軸ごとに「自身の反転 XOR 親の反転」で、真の軸だけ文字を打ち消す。画面の直下は `parent` 無し（自身の反転だけ）。`ObjectPainting.svelte` が Symbol の子を描くときに親の反転を渡して計算し、`Primitive.svelte` へ新しい prop で渡す。
- 打ち消しの変換は、文字の領域の中心 (ex, ey) = (width / 2, height / 2) のまわりで `matrix(sx 0 0 sy (1 − sx)·ex (1 − sy)·ey)`（sx・sy は打ち消す軸で −1、ほかは 1）。

### 色

- 文字色は `label.color`。塗りの `stateColor`（状態色）が効いても文字色は変えない（決定 5）。
- **Symbol 配置の単色モードでも文字色は `label.color` のまま**とする。単色モードは塗りと枠線を配置の色で上書きするので、文字まで配置の色にすると、塗りのある箱では塗りと同じ色になって文字が消える（新しい Symbol 配置の既定は単色モード）。Symbol の中の Text が配置の色になる今の規則とは違うが、`label` は形の一部の飾りではなく読ませる文字なので、こちらを採る。Symbol の縮小図（`SymbolThumbnail`）も同じく `label.color` で描く。
- 画面の直下の bool 表示の Text・表のセルの状態色の配色元に、`label` はならない。

### 外形・当たり判定・説明

- 外形（選択枠・範囲選択・整列・貼付けの基準）と当たり判定は変えない。文字は文字の領域の中に収まり、はみ出さない。
- 文字の部分は `pointer-events: none` にし、図形の当たり判定（多角形は形そのもの）で選ぶ。
- 省略された文言の全文を見る手段として、`Renderer.svelte` が Text にだけ付けている `<title>`（`onsummary` の説明）を、`label` 付きの面の図形にも付ける。`<title>` は配置の当たり判定の側に置くので、文字の `pointer-events: none` の影響を受けない。Symbol の子の文字の説明は、Text と同じく出さない（今も Symbol の子には `onsummary` を渡していない）。

### 通す画面

Designer・表示プレビュー・運転表示・画面の小窓・埋め込み・ミニマップ・Symbol の縮小図で、同じ部品（`Primitive.svelte`）を通す。お気に入りのアイコンは `Primitive` を通らず、初期形も文字を持たないので対象にならない。

## 編集

- **Inspector の置き場所**: 矩形・楕円・多角形の選択中に、塗り（`ShapePaint`）・状態色と同じく独立した draft を持つフォーム「文字」（`ShapeLabel.svelte`）を出す。object フォームの中には置かない（Text の `text`・`fontSize`・`textAlign`・`wrap` の欄と名前・draft が混ざらないようにする）。未適用の入力の保護（draft guard）・他フォームとの一括の事前検証は、塗りのフォームと同じ仕組みに載せる。
- **欄と確定**: 文言（複数行の入力）・文字サイズ・太さ・左右揃え・折返し・文字色。文言の欄の Enter は改行で、確定は Ctrl／⌘＋Enter か「変更を適用」（Text の文言の欄と同じ `textAreaKey`）。数値の欄は既存の数値の欄と同じく Enter・blur で確定する。IME の変換中は確定しない。文言を空にして確定すると `label` を消す。`label` が無い間の書式の欄は上の既定値を出し、文言と同じ確定で入る。
- **コマンド**: 単一 object の更新の patch に `label?: ShapeLabel | null` を足す（`null` は削除。`stateColor` の patch と同じ流儀）。面の図形以外は拒否する。文言は `normalizeTextNewlines` を通し、検査は保存契約と同じ関数で行う。同じ値なら no-op。1 回の確定が 1 回の Undo。
- **共通の操作**: 移動・回転・反転・複製・配列複製・整列・等間隔・ロック・表示切替・不透明度・重なり順・グループ・フォルダー・clipboard（同じ／別の Project）は、`label` を `shape` の一部としてそのまま持ち運ぶ。塗り・状態色の更新は `shape` を作り直さないので `label` は残る。
- **レイヤーの絞込み**: レイヤー木の検索文字列（`layer-tree.svelte.ts`。今は Text の文言・画面切替ボタンの文字・警報の小札の文字を含む）に `label.text` を足す。箱が 50〜80 個並ぶ画面で、文言で箱を探せるようにする。
- **Symbol 定義の中**: 定義の中の図形にも `label` を置ける。文言は定義で固定（配置ごとに変えるのは案 B）。
- **一括の文字書式**（`SelectionTextStyle`、Text だけを選んだとき）: 最初は広げない。`label` 付きの図形を含む選択は今までどおり拒否する。広げるかは使ってみてから決める。
- **初期形**（決定 6）: 挿入の多角形の初期形に「手入力の箱」（上辺が右上がりの四角形。頂点 (0, 0.25), (1, 0), (1, 1), (0, 1)）を足す。頂点は `lib/polygon-presets.ts` にまとめ、部品パレット・挿入メニュー・お気に入りのアイコンも同じ頂点から描く。初期形は文字を持たずに入る。

## 受入

- 矩形・楕円・多角形に文言を入れ、1 配置のまま移動・複製・整列できる（L2）。
- 回転（0°・90°・任意角）で文字が形と一緒に回る（L1）。
- `labelMirror` の単体試験（L1）: 自身の flipX・flipY と親の flipX・flipY の 4 × 4 の組合せ、子に回転がある場合。自身 flipX × 親 flipX は打ち消さない（偶数）、自身 flipX × 親 flipY は両軸を打ち消す。自身 flipX＋flipY は文字が正立、`rotation: 180` は逆さま。具体例として、親 flipX × 子 `rotation: 30` で、画面上の文字の角度が −30° になり、文字が鏡でない（文字の変換の行列式が正）ことを e2e で固定する。
- flipX・flipY・両方の反転で形だけ鏡になり、文字は読める向きのまま位置が変わらない。反転した Symbol 配置の中の `label` 付きの図形でも同じ（L1、e2e）。
- 折返し・明示の改行・高さ不足の省略・幅不足が、複数行の Text の経路と同じに出る。楕円では内接する矩形に収まる（L1）。
- 状態色で塗りが変わっても文字色は変わらない。Symbol の単色モードで、塗りのある図形の文字が `label.color` のまま見える（L1）。
- 省略された文言の全文が `<title>` で出る（L1）。
- 新しく作るときの文字色の既定の単体試験（L2）: 白・黒・`#b0b0b0` のような中間色（`#0f172a` を選ぶ）・暗い色（`#ffffff` を選ぶ）・比が等しい境目、塗り無し・グラデーション・模様（`canvasColors` 側）。
- 文言を空にして確定すると `label` が消え、元に戻すで戻る。Ctrl／⌘＋Enter と「変更を適用」で確定し、Enter は改行になる（L2）。
- レイヤーの絞込みで `label` の文言から図形を探せる（L2）。
- 保存して読み直しても文字と書式が変わらない（JSON と package の往復、複製、コピー・貼付け、別の Project への貼付け）（L2）。
- 工程の箱 10 個とひし形 3 個のフローを、Text を別に置かずに作れる（L3）。
- Rust と TypeScript が同じ契約ケースを通る（L1）。
  - 受け入れ: 矩形・楕円・多角形の `label`、`wrap` 無し・`none`・`word`、改行を含む文言、CR・CRLF・U+2028・U+2029 を含む文言（LF に正規化）、空白だけ・改行だけの文言、ちょうど 1 文字、ちょうど 1000 文字（サロゲートペアを含む場合を含む）、文字サイズ 512、大文字の hex の色、`label` 付きで `flipX`・`flipY` が真の配置、Symbol 定義の中の `label`。
  - 拒否: 空の `text`、1001 文字、`label: null`、`text`・`style`・`color` の欠落、`label` の中・`style` の中の未知の項目（`binding` など）、`style` の不正（文字サイズ 0・513、未知の太さ・揃え・折返し）、`color` の不正（3 桁・名前の色・α 付き）、`label` 付きでも root の `fill`・`colorAlpha`、面の図形以外（Text・Symbol・Image・Polyline・液位・表など）への `label`。
