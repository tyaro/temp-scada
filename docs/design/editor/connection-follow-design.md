## 初回の範囲

画面上のPolylineの始点／終点を、**同じ画面のSymbol配置枠**の上・右・下・左の辺中央または中心へ明示的に接続する。枠のローカル座標に配置の回転を適用し、Symbolの移動・サイズ変更・回転で接続端点を追従させる。接続口の名称・吸込／吐出の役割・Symbol内の絵柄や輪郭・Equipment上の接続は表現しない。Symbolのcontain余白があっても配置枠基準とする。表示上の線の交差と、保存された端点参照を区別する。

対象は画面上のSymbolとPolylineのみ。画像・矩形・Text・埋込View、Symbol定義内の接続、線同士の接続、任意の名前付きport、直交化・障害物回避・自動routing、設備の制御関係、Hub／serverは対象外。非表示のSymbolも参照を保持する。初回UIではInspectorの明示選択を優先し、マウス吸着・作成ツールは別工程とする。

## I8bの保存・追従契約

Polylineのshapeに任意の`connections: { start?, end? }`を保存する。各端の参照は`{ targetObjectId, anchor }`。参照先は同一画面の配置IDであり、Symbol定義IDやEquipment IDではない。各端点は独立し、同じSymbolの異なるanchorも選べる。循環する線参照は型と対象制約で導入しない。

**保存pointsは、接続解決済みの実際の形状**とする。描画ごとに別の形状へ置換するモデルにはしない。既存の選択・hit領域・ミニマップ・埋込・小窓・書出しが同じpointsを使う。読込では参照先の存在・種別・所有者・anchorと、端点world座標の一致を検証し、不一致を黙って補修しない。TS／Rustはworld座標のx／y各成分の絶対差`1e-7`を許容する。I8bで保存版をProject0.35.0へ進め、schema・TS／Rust・共通ケース・現行サンプルを同時に更新した。I8a時点は0.34.0を維持した。0.34.0からの自動移行は追加しない。

`editor.ts:finish`の候補確定前に追従を一箇所で解決する。既存Projectは変更前に検証し、接続先の消失や不正形状をfinishの補修で隠さない。接続・解除と他の編集は既存command／Undoへ接続する。ドラッグ途中も同じ幾何を使い、確定時だけ端点が跳ぶ状態は受入不可。

## 幾何の不変条件

- Symbolのanchorは配置枠の寸法・中心・回転だけで決める。定義内の絵柄・定義サイズ・state色・原本画像・設備値からは求めない。
- 接続先だけの変更では、**中間点と未接続端点のworld座標を保持**する。
- 線も移動・回転等を行うときは、通常変換後の線を入力し、その時点の中間点・自由端点を保持して接続端点を再解決する。同時移動で端点を二重にずらさない。
- 線の回転中心は点列boundsから導出される。両端を**変更前の同じ変換**でlocalへ戻し、同時更新後のpivot差をx／yへ補正する。順次更新やpointsの単純な上書きに依存しない。
- 原点が負、任意回転、端点と中間点の大小関係が逆転、両端同位置でも中間点が残る形を扱う。全点一致と非有限値は拒否し、入力を変更しない。有限でも大きな座標による丸めで保持精度を満たせない操作は拒否する。すべての出力頂点を要求端点／元のworld座標と照合し、端点だけの検証で中間点のずれを見逃さない。
- 解決済みの端点が許容誤差内なら元のオブジェクトを返し、反復解決で微小差を保存・Undoへ増やさない。座標の丸め・グリッド吸着・経路最適化をここへ混ぜない。

## 編集・削除・ロック・グループ

接続／解除は明示操作。解除は現在の端点形状を保持し、1回のUndoで戻せる。接続端点の直接ドラッグは拒否して解除を案内し、中間点の編集は許可する。

生き残る線から参照されるSymbolの削除・cutは使用先を示して全体拒否する。線も同時に削除する場合は許可。cutは書込開始前にも検査し、既存の非同期書込成功後の削除・所有者照合を維持する。自動detachで関係を消さない。

追従によってロックされた線の形状が変わるときは、接続先の操作ごと原子的に拒否する。接続先の色・名前変更など、端点が変わらない編集は妨げない。Symbol側のロックは既存の直接編集保護を維持する。

初回はgroup内の線への接続と、接続線をgroupへ入れる操作を拒否する。Symbolがgroupに含まれることは許可し、そのgroupの移動／回転で外部の線を追従させる。整理フォルダーはgroupではなく、接続の所有者境界にしない。

## 複製・clipboard

コピー集合内に含むSymbolへの接続だけを保持し、配置ID対応表で新しいSymbolへ再配線する。集合外への接続は外し、見えていた形状を複製する。同一workspaceだからという理由で古い配置へ再接続しない。片端だけ含む場合も端点ごとに適用する。この規則は操作ガイドとUI説明に示す。

Symbolだけ複製しても元の線は元Symbolを参照する。画面複製は画面内の参照をすべて対応付け、配列複製は組ごとのID対応表を使う。別画面・別Projectへ元の配置IDを持ち込まない。group・slot・状態色・画像原本の既存コピー契約を維持する。

## Issue #306：矩形・楕円・多角形への接続（設計、2026-11-21）

ほかの未決は次のとおりに置く（設計 PR のレビューで変えてよい）。

- Text・画像・表・埋込 View への接続は入れない。文字入りの図形（#305、`graphics/shape-label.md`）が入ったので、箱に文言を持たせて図形へつなぐ。
- 保存版は **0.37.0 のまま**。schema の `endpointConnection` は配置の id と anchor だけで接続先の種別を持たないので変わらない。変わるのは TS と Rust の接続先の検査だけで、接続先を図形にしたファイルは E1 より前の版では読込の検査で理由つきで拒否される（黙って読み違えない）。リリース前の Project は後方互換を保証しない方針（2026-10-18）にも合う。

### 接続先と anchor

接続先は同じ画面の `shape.type` が `symbol`・`rectangle`・`ellipse`・`polygon` の配置。anchor は今の 5 つ（`top`・`right`・`bottom`・`left`・`center`）のまま。どの種類も、配置の中の座標（枠の左上が原点）で点を決め、既存の `objectToWorld`（Rust は `world`）で反転・回転を当てて world の点にする。別の回転系は作らない。

| 種類   | 辺の anchor（配置の中の座標）                  | `center` |
| ------ | ---------------------------------------------- | -------- |
| Symbol | 枠の辺の中央（今のまま）                       | 枠の中心 |
| 矩形   | 枠の辺の中央                                   | 枠の中心 |
| 楕円   | 枠の辺の中央。楕円の頂点に一致する             | 枠の中心 |
| 多角形 | 中心線と外周の交点のうち辺に最も近い点（下記） | 枠の中心 |

- anchor は形の幾何の外周で決め、枠線の幅・点線・塗り・状態の色・文字（`label`）からは求めない。矢印の先は枠線の中心線に当たる。
- `center` は多角形でも枠の中心のまま（凹んだ形では形の外に出ることがある）。重心にすると頂点の編集で中心の意味が変わるため。

### 多角形の anchor

辺の anchor は、頂点の割合（`PolygonShape` の 0〜1）の空間で、枠の中央を通る線と外周との交点のうち、その辺に最も近い点とする。

- `top`・`bottom`: 縦の中心線 `u = 0.5` と外周の交点のうち、`top` は `v` が最小、`bottom` は `v` が最大の点。
- `left`・`right`: 横の中心線 `v = 0.5` と外周の交点のうち、`left` は `u` が最小、`right` は `u` が最大の点。
- 得た割合の点 `(u, v)` に幅・高さを掛けて配置の中の座標にし、`objectToWorld`（Rust は `world`）で world へ写す。

この規則は「中心から辺の中央へ向けた線と外周の交点のうち外側のもの」を、反対側の辺まで延ばした中心線へ広げたもの。中心から引いた線が外周と交わる形では同じ点になる（2026-11-21 のユーザーの決定「外周へ寄せる」）。延ばすのは、凹んだ形で中心が形の外にあり、中心からの線が形をよけるときにも点を 1 つに決めるため。外周は閉じていて、外接矩形が枠そのもの（`u`・`v` とも最小 0・最大 1）なので、中心線とは必ず交わる。

交点は次の式で、TS と Rust で同じ順序で求める。許容誤差は使わない。

- 辺は最後の点から最初の点へ閉じた辺を含む、頂点の順の全ての辺 `A→B`。
- 縦の中心線では、`min(A.u, B.u) <= 0.5 <= max(A.u, B.u)` の閉区間を厳密に比べて交わる辺を選ぶ。頂点がちょうど線の上にある（接するだけの）ときも交点に数える。`A.u == B.u == 0.5`（辺が線に重なる）ときは `A.v` と `B.v` の両方を交点にする。それ以外は `t = (0.5 - A.u) / (B.u - A.u)`、`v = A.v + t * (B.v - A.v)`。横の中心線は `u` と `v` を入れ替えた同じ式。
- 割合の空間で決めるので、anchor は割合の定点になり、大きさの変更で交点の選び方が丸めで揺れない（拡大・縮小はアフィンなので交点と順序は変わらない）。

枠の辺の中央と同じ点になるかは辺ごとに違う。枠の辺の中央が外周の上にある辺（矩形・ひし形の 4 辺、台形の上下、正五角形の `top`）ではその点になる。正三角形・正五角形の `left`・`right` のように辺の中央が外周に乗らない辺では、中心線の高さの外周の点になる（正五角形の最も左の頂点は高さの約 38% にあり、`left` はその頂点ではなく `v = 0.5` の斜辺の上の点）。

- 凹んだ形では、頂点の編集で中心線をまたぐ外周の部分が入れ替わると、anchor が大きく動くことがある（どの規則でも残る）。操作ガイドの注意として E2 で書く。
- 自己交差・折り返し（とげ）のある多角形は、今の検査（`validatePolygonPoints`）が受理するので、規則は辺の集合のまま当てる。anchor が塗りの内側の辺やとげの先に乗ることがあるが、見た目は保証しない。契約ケースに 1 件入れる。
- anchor の関数は、多角形の前提（頂点の数・外接矩形が枠・幅と高さが正）を満たさない入力では例外を投げる。一時の候補でも呼ばれるので、Renderer は既存どおり確定済みの形を表示し、確定の操作で理由を返す。読込では多角形の検査が接続の検査より先に走る（TS・Rust とも）。

頂点の編集（`reframePolygon`・頂点のドラッグ・頂点の文字での入力）で外周が変わると anchor も動くので、接続中の線は追従する。これは移動・大きさの変更と同じく `editor.ts:finish` の追従と Renderer の一時の投影が受け持つ。ただし今の頂点のドラッグの投影（`previewPolygonVertex`）は枠を作り直さず、割合が 0〜1 の外へ出る。そのままでは、ドラッグ中は古い枠、確定後は作り直した枠で anchor を求め、確定で端点が跳ぶ（I8 の受入不可の状態）。接続の解決へ渡す候補は `reframePolygon` を通した形にし、作り直しが拒否される形（幅・高さが小さすぎるなど）では確定済みの形を表示する。

### 編集・削除・ロック・グループ・複製

Symbol 配置への接続と同じ規則を図形にも当てる（上の「編集・削除・ロック・グループ」「複製・clipboard」）。

- 生き残る線から参照される図形だけの削除・切取りは、使用先を示して全体を拒否する。
- 追従でロックされた線の形が変わる操作は、接続先の操作ごと拒否する。図形の色・文字・状態の色の変更など、anchor が変わらない編集は妨げない。
- group に入った図形への接続は許し、group の移動・回転で外の線を追従させる。group の中の線の接続と、接続線の group 化は今のまま拒否する。
- 複製・貼付け・画面複製・配列複製は配置の id の対応表で振り直す。集合の外への接続は形を保って外す。
- 選んだ図形を Symbol 定義へまとめる操作と、図形の種類を変える操作は、2026-11-21 の時点で無い（`create-symbol` は名前と寸法から空の定義を作るだけ）。どちらかを足すときは、外の線から参照される図形が接続先の 4 種から外れる操作を、削除と同じく使用先を示して拒否する。
