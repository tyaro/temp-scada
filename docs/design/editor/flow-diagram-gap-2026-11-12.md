# 目標のフロー図と現状の差分（2026-11-12）

作成: 2026-11-12（日本時間）。状態: **洗い出し・優先順位案（ユーザー確認待ち）**。実装の採用や完了を示さない。

## 1. 目標

オーナーが示した実プラントの SCADA 画面8枚（焼却炉の全体、給排水、吸収塔、搾汁・前処理・糖化・発酵・培養の各設備）の水準のフロー図を、Designer で描けて、運転画面として表示できること。参照画面は Git 管理外で、このリポジトリへは画像・切り抜き・トレースを入れない。以下は文章だけで書く。

参照画面に共通する要素:

- 系統ごとに色分けした密な配管（実線・破線の信号線）、矢印、分岐・合流、交差。
- 機器の記号: 弁（XV／TV／FV／LV／PV）、ポンプ、ブロワー、槽、塔、サイクロン、熱交換器、撹拌機、斜めのコンベヤ、スクリューフィーダー。
- 槽の液位の塗りつぶし。
- 単位つきの数値表示（Hz、mm、m3/h、kPa、℃、pH など）。
- HH／H／L／LL／AH／SL の警報限界の小札（状態で色が変わる）、`*` 印、番号の小札。
- 状態色のセル（運転中、一括故障、連動運転選択中など）。
- 表: 工程表（開始・完了・未、時刻）、メッセージ表示、設定値・PV の表。
- 画面外への接続矢印（CWS、CWR、LPS、CIPS、ATM など）。
- 画面の枠: 上端に画面名・最新の警報・アラーム履歴／ブザー停止／印刷・日時、下端に現在の画面を強調した画面切替ボタン列と前後ボタン。
- 機器のステータスは、ビット割付（状態ごとに1つの bool）とワード割付（1つの整数ワードの値、またはワード内のビットで状態を表す）の両方がある。

## 3. 優先順位案

上流の契約に依存しない表示の機能を先に進める。C6（連続運用試験）とは独立して進められる。

段階1（表示の基本。Designer と表示だけで完結）:

1. **状態の多値表示（#5・#6）**: ビット割付とワード割付の両方を扱う。slot とタグ結合に「ワード」「ワードのビット」を足し、値ごとの色・文字の対応表を機器種別か Symbol 定義に持つ。bool の状態文字もここで解く。参照画面のほぼすべての機器表示がこれに依存する。
2. **数値の書式（#4）**: 小数桁・単位の表示・範囲。数値の表示はどの画面にも多い。
3. **液位（#3）**: 数値に比例する塗り。槽の表示に必要。
4. **部品と反転（#2）**: 主要な機器の組込み部品の追加と、左右・上下反転。利用者の Symbol 定義で代用はできるので、1〜3 の後でよい。
5. **配管の仕上げ（#1）**: 分岐の点・交差のまたぎ・始点の矢印・画面上の状態色。
6. **表（#8）**: 固定文字とタグ結合のセル。工程表は多値表示（1）に依存する。

段階2（運転画面の構成）:

7. **画面の枠と画面切替（#10・#11、#9 の画面切替だけ）**: ヘッダー・時計・画面切替ボタン列と、Designer と分けた運転画面。書込みを伴わないので段階3を待たない。

段階3（上流の契約・別工程に依存）:

8. **警報（#7）**: v1.1 S10 の警報 Engine と合わせて、限界の評価・小札・点滅・警報帯・履歴。
9. **操作（#9）**: 上流の書込み契約の成立後に、運転・停止・設定値・Faceplate。

## 4. 確認したいこと

- 優先順位の段階1の順でよいか。C6 との前後関係。
- ワード割付の状態定義（値ごと・ビットごとの色と文字）を、機器種別に持つか、Symbol 定義に持つか。同じ機器種別でも PLC ごとに割付が違うことがあるか。
- ワード内のビットで状態を表す場合、1つの機器に複数の状態（運転・故障・自動など）を同時に持つか。持つ場合の表示の優先順位。
- 液位を Symbol 定義の中の部品として持つか、画面に直接置く図形にするか。

### 5.1 開始時に決めること（推奨の既定）

| 決めること                         | 推奨の既定                                                                                                                 | 理由                                                                                                 |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 段階1の順番と C6 の前後            | 段階1 を A（状態）から始める。C6 は実機の都合で並行に進められる（コードを共有しない）。                                    | 参照画面のほぼすべての機器表示が状態の多値表示に依存する。                                           |

### 5.2 段階1-A 状態の多値表示（ビット・ワード）

- **A1 モデル**:
  - Project に `stateTables` を追加する。各状態表は `id`・`name`・`source`（`bool`／`value`／`bits`）・`rows`（`match`・`text`・`color`）・`otherwise`（`text`・`color`）を持つ。
  - `match` は、bool なら true／false、value なら整数（範囲指定は後回し）、bits なら `{ bit, on }` の組（ビットは 0〜31、複数の条件は AND）。
  - slot の型に `word` を加え、slot に任意の `stateTableId` を持たせる。
  - 整合検査: 参照先の有無・slot の型と `source` の対応・ビットの範囲・重複。
  - 試験: Rust の schema 検査と `equipment.rs` の検査、TS の `validateEquipment`、新しいサンプル `examples/state-table.project.json` の往復。
- **A2 評価**:
  - 純関数 `evaluateState(table, value)`（`lib/state-table.ts`）で、表示する文字と色を返す。
  - 整数でない値・範囲外・品質不良は「不明」とする。値は f64 で届くので、ビットの取出しは安全な整数（2^53 未満）に限る。
  - 試験: `state-table.test.ts`（値・ビット・優先順位・不明）。
- **A3 表示**:
  - 状態表つきの slot に結合した Symbol 内の文字は、状態の文字と色を出す。
  - 既存の `stateColor`（図形・配管が bool の文字に従う）を、状態表つきの文字にも従えるよう一般化する。
  - bool の slot にも状態表を付けられるようにする（運転／停止の文字）。
  - 試験: `slot-presentation` の単体試験と、プレビューの e2e（モックの読取で値を変え、色と文字が変わることを確かめる）。
- **A4 編集 UI**:
  - プロジェクトタブに状態表の一覧と編集ダイアログを置く。
  - 機器種別の slot 編集で、型 `word` と状態表を選べるようにする。
  - 試験: e2e（状態表の作成・slot への割当・保存と再読込）。
- **A5 画面上の直接結合**:
  - 画面に直接置いた文字のタグ結合にも、状態表（とビット）を指定できるようにする。
  - 画面上の配管・図形の状態色も、それに従えるようにする。
  - 試験: 単体試験と e2e。

### 5.3 段階1-B〜F

- **B 数値の書式**（依存なし）:
  - 数値を出す文字に `format: { decimals, unit }` を持たせる。単位は Project に文字で保存し、編集時にタグ一覧の単位を初期値にする。
  - `presentNumeric` が書式を受ける。slot の数値も同じ書式を使う。
- **C 液位**（B の書式を表示に使う場合だけ B に依存）:
  - 図形 `level` を追加する（`min`・`max`・向き（上・右）・塗りと地の色）。
  - Symbol の中では number の slot に、画面では直接結合に従う。
  - 品質不良・範囲外のときは塗らずに、その状態を示す。
- **D 部品と反転**（依存なし。反転と部品は別の PR にする）:
  - `BaseObject` に左右・上下反転を加える。回転・選択枠・接続点・Symbol の中の扱いを揃える。
  - 組込み部品（`symbol-library.json`）に、ブロワー・槽・塔・サイクロン・熱交換器・撹拌機・コンベヤ・スクリュー・モーターを追加する。
- **E 配管**（画面上の状態色だけ A5 に依存）:
  - 始点・両端の矢印を加える。
  - T 字の接続には分岐の点を描く。
  - 交差のまたぎを描く（描画時に計算し、画面ごとに入切できる）。
- **F 表**（A・B に依存）:
  - 図形 `table` を追加する（行・列・列幅・罫線・セルの色）。
  - セルは固定文字か、タグ結合（B の書式・A の状態表を使う）。工程表・SV／PV 表を描けるようにする。

### 5.4 段階2 画面の枠と画面切替（計画は段階1の後に詳しくする）
