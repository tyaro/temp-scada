#### P0-1 「記録を停止」に確認がなく、記録中かどうかを常時示す表示もない

- 確認方法: ［コード］＋［モックIPC］。実 Hub・実 Tauri では未確認。
- 画面と手順: 表示 → 記録管理状態 →「状態を照会」→「記録を停止」。
- 困ること:
  - 「記録を停止」は `onclick={() => void stop()}` で即実行され、確認がない。3つ並ぶボタンのうち、記録中に押せるのはこれだけで、最も目立つ。連続運用中の押し間違いが、そのまま欠測になる。
  - 記録の状態は、このダイアログを開いて「状態を照会」を押さないと分からない（「画面を開くだけでは照会しません」と明記）。ヘッダーには認証と Hub の表示しかなく、「記録中」の文字はアプリ内でこのダイアログの説明文にしか出てこない。
  - 照会結果は `snapshot commit`、`activation ID`、`phase`、`cleanup` などの診断項目の並びで、「いま記録しているか」を一言で示す行がない。
- 修正案:
  1. 「記録を停止」に Banto の Modal で確認を入れる（止まる対象、再開の手順、欠測になることを書く）。
  2. ダイアログの先頭に「記録中／停止中／中断」のバッジと、最終記録時刻を置く。診断項目は折りたたむ。
  3. ネイティブのヘッダー（認証・Hub の並び）に記録状態のバッジを足す。自動照会を入れない方針なら「最終照会 hh:mm」を添える。

#### 5.3.2 操作の流れの指摘

##### F-1（P1）別の場所へ行って戻ると、選択が外れ、Symbol 編集からは表示位置も飛ぶ

- 確認方法: ［実画面］
- 再現A: 編集で図形を選ぶ → 表示プレビュー → 編集。「0 件選択」になる。倍率と左タブは保たれる。
- 再現B: `process.project.json`、倍率 200%、ポンプを選ぶ →「参照する Symbol 定義を編集」→「画面へ戻る」。倍率は 200% に戻るが、図面の左上が (-13,2) から (648,397) に変わり、ポンプは画面外になる。選択も外れる。
- 困ること: 「プレビューで見て直す」「定義を直して結果を見る」は、どちらも往復が前提の作業。戻るたびに対象を探してクリックし直す。B では探す範囲が画面外になる。Symbol 編集に入ると左タブも「プロジェクト」へ切り替わるので、図形を足すには「部品」を押し直す。

- 困ること:
