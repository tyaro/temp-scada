# 図形間の隙間の均等化

状態: Project0.31.0の共通作図操作。保存項目は追加しない。[現場作図の追加提案§4](../proposals/scada-authoring-plant-operations-proposal.md#4-図形合成部品作成作図補助)の寸法・配置補助の一部。

## 操作

3単位以上を選び、共通ツールバーまたは右クリック／キーボードの選択メニューから「隙間を水平方向に均等化」「隙間を垂直方向に均等化」を実行する。従来の「中心を等間隔」はそのまま残す。共通操作はプロパティへ追加しない。

異なる幅・高さの図形も、**回転後の外形の間の隙間**を揃える。既存の外形計算を使い、配管の矢印も考慮する。幾何グループは一単位とし、メンバーの相対位置を保つ。共有定義内でも同じ操作が使える。

## 順序と計算

1. 対象軸の中心で昇順に並べる。中心が同じ場合は描画順を維持する。
2. この順序の最初と最後の単位を固定する。両端の外側の距離から全単位の寸法合計を引き、単位間の個数で割る。
3. 残る隙間が負なら「両端の間に収まりません」と全体を拒否する。重なりの均等化はこの操作へ含めない。隙間0は許可する。
4. 中間単位だけを対象軸に沿って移動する。反対軸・寸法・回転・描画順・フォルダー・機器やタグの参照は保持する。

座標はスナップで丸めない。極端な有限座標の距離や寸法合計がoverflowしないよう正規化し、寸法の合計と中間位置の累積は補償付き加算で計算する。浮動小数の丸め範囲内は同値とし、再実行による微小移動の履歴を作らない。

## 入力と原子性

既存の未適用入力・対象世代・編集モード・ロック・完全グループ選択の保護を共用する。選択内の操作できる図形だけを暗黙に変更しない。失敗時は変更なし、成功時は一回のUndo。未適用の色などを「適用して続行」で確定した場合は、その入力のUndoと配置のUndoを別に保つ。

後続: 任意隙間の数値指定、固定端の指定、ドラッグでの配列補助、重なり量の均等化。グループ任意拡縮・入れ子はこの工程とは別。
