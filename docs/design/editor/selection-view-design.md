## 操作と表示範囲

編集モードのツールバーで「全体表示」の隣に「選択範囲を表示」を置き、表示メニューからも実行できる。キャンバス／レイヤーの配置行で修飾キーなしのFも使える。1回の操作で倍率・中心を合わせ、以後の選択変更・編集へ自動追従しない。全体fitとは別の手動倍率として画面ごとの既存viewに保持し、「全体表示」で戻せる。

対象は選択した配置の描画外形。太い枠線・線／配管の矢印を含み、Symbolは定義のviewportを基準とする。配置ごとに画面との交差を計算してから外接範囲を求める。完全に画面外の配置だけで、空の画面領域が対象になることを防ぐ。非表示を含む場合は全体を無効にし、黙って除外しない。visibleなlocked配置は表示できる。塗り・枠線が両方ない形状も、編集用選択枠の位置を確認できる。

選択なし・参照切れ・全件画面外は理由付きで無効。部分的に画面外の場合は表示可能部分へ合わせ、完全に画面外の配置の件数と、画面外の部分を表示していないことを通知する。選択や座標は保持する。画面外まで編集可能なworldの新設は含めない。

ルーラー・スクロールバーを除いた実際のclient領域から、各辺32 CSS pxの余白を取る。表示移動でスクロールバーが現れる場合は初回の配置を再計算する。倍率は25〜400%を優先し、巨大な対象が25%でも収まらない場合は中心へ寄せる。全対象が常に画面内へ収まる保証はしない。極端な有限値による演算のoverflowも拒否し、NaN／Infinityをviewへ保存しない。

## 入力と操作の分離

Project・選択・revision・Undo履歴を変更せず、未適用入力を適用／破棄する確認も要求しない。ツールバーのポインタ操作ではボタンへフォーカスを移さず、入力中の有効／不正な数値もそのまま保持し、適用済みの図形の位置へ合わせる。

入力欄でFを奪わない。Ctrl／Command＋F、Shift／Alt修飾、IME・keyCode229・repeat、メニュー・Modal・タグ選択中は対象外。連続配置・図形の移動／サイズ／頂点編集・範囲選択・パンの途中にも実行しない。表示プレビューでは使わない。

数値欄からTabやメニューを開く操作などでフォーカスが移った場合は、既存のEnter／blur確定の規則を維持する。表示操作そのものから既存のdraft guardやcommitを呼ばない。
