# Textの基本書式と枠内表示

文書の位置付け: **採用済み設計・導入時の実装記録。文中の旧版・件数・当時の未実装表記は記録時点のもの。** 現在の対応範囲と保存契約は[実装状況](implementation-status.md)を正とする。

2026-10-19。基準は[統合設計](scada-integrated-design.md)。AstraのUXレビューに従い、工程図の見出し・機器名・数値表示を整える。実装・検証の記録は[開発計画](development-plan.md#text-style-progress)に記載する。

## 保存するもの

Project／最小Runtimeを0.12.0とし、画面と共有Symbol内部のTextに必須の `shape.style` を持たせる。

| 項目       | 契約                                            |
| ---------- | ----------------------------------------------- |
| fontSize   | design unit。0より大きく512以下の有限数         |
| fontWeight | normal／bold                                    |
| align      | left／center／right                             |
| text       | 最大1000文字の1行。CR・LF・U+2028・U+2029を拒否 |

文字列・書式だけを保存し、計測結果・省略した文字列・現在値を保存しない。0.11.0のファイルは自動移行せず拒否する。従来の0.1.0移行では、角度0と通常・左揃えの書式を補う。旧Textの既定サイズは高さ×0.7を上限512へ収め、保存する枠寸法は保持する。現行サンプルの初期サイズは従来の高さ×0.7を明示値にし、その後のリサイズでは変更しない。

## プロパティ操作

単一Textの文字サイズは座標と同じEnter／フォーカス移動確定・Esc取消・IME保護を使う。標準／太字、左／中央／右と文字列は既存の「変更を適用」にまとめる。他の未適用入力を失わず、ロック・非表示・共有定義の既存規則とUndoを共用する。改行を含む貼付は拒否して案内し、黙って連結しない。

枠の幅・高さと文字サイズは独立する。上下は中央固定、横は左右2 design unitの余白を使う。フォントは共通のArial／Noto Sans／Noto Sans CJK JP／sans-serifの順に明示する。フォントファイルの同梱・フォント選択・複数行・縁取り・書式の一括編集は後続。

## 枠不足の表示

SVGで実際の文字外形を計測し、文字数による推測やズーム後のpixel寸法を使わない。行高の目安1.2×文字サイズと実際の外形の両方を確認する。自動縮小は行わない。

- 静的Textの横超過は末尾「…」。Intl.Segmenterで書記素を保ち、結合文字・絵文字を分断しない。
- 数値タグは桁・符号・小数点を一部だけ残さず、表示全体を「###」に置換する。未接続等の状態文字も同じ規則を使う。
- 縦不足、または代替文字も入らない小さい枠では、枠内に収まるベクターの警告記号を使う。
- 空文字は意図した空表示とし、警告を出さない。
- 全文・状態・枠不足の理由をSVGのアクセシブル名とtitleへ渡す。編集用hit領域でも同じ説明へ到達できるようにする。

最外のText viewportをクリップし、回転後も宣言した枠からはみ出さない。選択・範囲選択・整列・選択fitはこの枠を使い、フォント計測を保存モデルの幾何計算へ混ぜない。タグのQuality／解決状態を枠不足に書き換えず、正常値へのフォールバックもしない。

## 計測のライフサイクル

文字列・書式・枠寸法のkeyとフォント完了／失敗の通知で再計測する。初回の未計測中は値の一部を描かず、警告を使う。別配置の編集・ズーム・回転・選択だけでは再計測しない。

非表示中に計測が失敗した場合は未計測とし、ResizeObserverで表示領域の復帰を確認して再試行する。成功済みのTextについては、同Observerがズームに応答しても再計測しない。Editor／表示プレビュー／ミニマップ／Symbolサムネイルは同じPrimitiveを使う。各ブラウザ・OSのフォント差までpixel一致を保証するものではなく、同梱フォントによる固定は後続とする。

## 受入条件

Rust／TypeScriptで同じ書式・1行境界fixtureを検証する。ブラウザでは両テーマ、Enter／blur／Esc／IME／draft、Undo／Redo／JSON、回転、共有Symbol、非表示からの復帰、フォント更新、静的長文・日本語・絵文字・数値枠不足を確認する。無関係な編集やズームが余分な文字計測を起こさないことも確認する。
