# レイヤー配置のドラッグによる所属変更

後続の[フォルダー自身のドラッグ](folder-drag-design.md)を0.12.0で追加した。本書の以下は配置ドラッグを導入した時点の範囲を記録する。

基準: [統合設計](scada-integrated-design.md)・[フォルダー設計](layer-folders-design.md)。フォルダーは整理用の所属で、座標変換や描画順を持つ幾何グループではない。Project 0.10.0と既存のset-folderコマンドを使用する。

## 操作

配置行の名称／アイコンをドラッグして、フォルダー行の直下へ移す。選択済みの行から開始した場合は選択全件、未選択の行からはその1件を対象にする。ドラッグ開始だけでは選択・所属・履歴を変えない。通常のポインタによるフォーカス移動では、既存の数値blur確定規則を維持する。

ドラッグ中は対象件数・非表示件数・移動先パスを表示する。フォルダー行全体を強調し、挿入線は使わない。閉じたフォルダーにもドロップでき、成功すると所属先とその祖先を展開する。「フォルダーから外す（ルートへ）」領域はドラッグ中だけ表示する。長い一覧はパネル上下端で自動スクロールする。

目・錠・操作ボタンとフォルダー自身はドラッグ元にしない。配置行へのドロップで並べ替えない。Ctrl等を押しても複製しない。フォルダー自身の親変更は既存のメニューを使う。キーボードやマウス以外では既存の「配置の所属を変更」ダイアログを使用する。

検索は自動解除しない。移動後に検索条件から外れた場合は案内し、選択を保持する。条件内なら移動した先頭配置を一覧内へ表示する。配置の名前・座標・サイズ・描画順・表示・ロック・図面の倍率は変更しない。複数変更は1回のUndo。同じ所属へのドロップは履歴を増やさない。

## 入力と対象の保護

ドラッグ元IDと所有先・読込世代を開始時に固定する。DataTransferには専用MIMEの推測困難なセッショントークンだけを渡す。外部テキスト・ファイル・部品パレットのデータや別セッションのトークンを編集要求として扱わない。

ドロップ時に対象ID・移動先を取り込んでから既存draft guardを通す。確認をキャンセルすれば入力と所属を保持し、適用時の不正値でも所属を変えない。確認中のnative dragendは、取り込み済みの意図を消さない。確認後に世代・所有先・全配置ID・移動先・ロックを再検証し、黙って対象を削らない。

非表示配置は件数を示して移動でき、表示に戻さない。ロック混在は全体を拒否する。タブ・所有先・モード・左パネル表示の変更、Esc、ドラッグ終了、ウィンドウのフォーカス喪失で未ドロップのセッションを無効にする。完了直後のマウスclickで選択が変わることを防ぐ。

## 後続

フォルダーのドラッグ、手動並べ替え、複数所有先間の移動、幾何グループ、タッチ専用ジェスチャーは含めない。これらは保存契約・操作意味・入力保護を別途設計する。
