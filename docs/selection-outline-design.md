# 矩形・楕円の枠線の一括編集

状態: **Astraレビューを反映した次の実装仕様。未実装**。Project 0.10.0のpaintを使い、schemaは変更しない。矩形・楕円だけの複数選択を対象とし、塗り・幾何・所属を変更しない。

## 指定と適用

現在値と変更指定を区別する。フォームは枠線「変更なし」、色は未指定、幅は空欄から始める。現在の枠線あり／なし件数を示す。色／幅の共通値・混在は枠線ありの対象だけで集計し、全件なしなら現在の色・幅も「なし」とする。

- 枠線「変更なし」: 色または幅を指定した場合、その属性だけを変更する。対象全てに枠線が必要。枠線なしを含む場合は全体拒否して「あり」の明示指定を求める。
- 枠線「なし」: 全対象のstrokeをnullへ変更する。色・幅との同時指定を拒否し、余分な指定を黙って捨てない。
- 枠線「あり」: 既存の枠線は未指定の属性を保持する。新たに枠線を作る対象がある場合は、色・幅の両方を明示指定する。既定色や幅を暗黙補完しない。指定した色・幅は、新設対象だけでなく既存枠線も含む選択全体へ適用する。

色だけ／幅だけの部分変更に対応する。色は6桁HEX、幅は0より大きく64以下。全指定なしは適用不可。単色Symbolの親配置から内部の枠線は変更しない。Text／線／Symbolを含む選択を暗黙抽出せず、対応対象の選択を案内する。

## コマンドと入力保護

set-outline-styleにobjectIdsとpatchを渡す。patchは任意のmode（none／enabled）、color、widthだけを許可する。「なし」と色／幅の同時指定、未知キー・空patch・不正型・非有限数・範囲外・重複ID・参照切れ・非対応型・locked混在を全体拒否する。枠線新設の必要属性を、変更前の全対象に対して事前検証する。

hidden対象は件数を明示して編集でき、表示へ戻さない。modeなしは既存状態を維持する。同値への適用はrevision・履歴を増やさない。色の大文字／小文字だけの違いで履歴を増やさない。

フォームは独立draft・対象世代／owner／選択IDの固定・通常Enter／IME保護・明示適用・全フォーム事前検証へ接続する。blurでは変更せず、成功後は未指定へ戻す。1回の適用をUndo1回にまとめる。共有定義の明示編集中は内部図形だけを変更し、親配置の寸法や単色モードを維持する。

## 受入条件

- 既存枠線の色／幅だけの変更、明示解除、枠線新設、既存／なし混在、未指定属性の保持、矛盾指定・不足指定・不正値の全体拒否を確認する。
- 塗りの有無と保存色、座標・本体寸法・所属・順・非表示・選択・倍率・中心を保持し、描画外形だけが線幅へ追従する。
- 同値no-op、Undo／Redo／JSON、ロック・混在型・非表示、他フォーム不正時の一部適用なし、IMEを確認する。
- 両テーマと狭幅、共有定義内編集と通常画面を実ブラウザで確認する。
